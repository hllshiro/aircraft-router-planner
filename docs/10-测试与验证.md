## 3. 崩溃/退化输入套件（crash_suite.rs）—— B9 显式验收项

**十四轮终裁**："绝对不能崩溃"必须有可验证抓手，不测等于没承诺。入 CI **一票否决**（任何 panic 用例 = 验收失败）。

覆盖范围：

| 模块 | 用例 |
|------|------|
| config | 空输入、null、类型错误、缺必填、NaN 坐标、超界纬度、畸形 JSON |
| coord | NaN/极端反算（TM 大坐标回代） |

## 4. 回归套件（regress_phase0.rs）—— 历史 bug 防复发

**背景（主管拍板 2026-08-06）**：`phase0_out/` 中 18 个输入型 mission JSON 是历史上主管反馈 bug 的原始输入（锯齿/直穿 restricted/禁飞区陷阱/restricted 高度层剖面判据等）。复制为正式回归用例，防止错误复现。

**回归语义（核心断言）**：
1. 每个输入 parse + validate + solve 全过（不 panic、不 Err）；
2. 输出路径逐点不穿任何 zone（水平包含 + 高度带，与 `zone_contains_at` 同语义）——no_fly/obstacle 全高度禁入，restricted 仅禁入高度带（底部/顶部剖面穿越合法）。

**强断言防锯齿复发**（对应历史修复，见 07 文档）：

| 用例 | 断言（<30 点 + 无 smoothing_failed） | 防回归的修复 |
|------|--------------------------------------|--------------|
| zigzag11 | 段边界入口航向约束（61.94°>60° → 终检拒 → 全链回退） | Theta\* 首跳入口航向约束 |
| zigzag12 | 剖面 out→climb 过渡直线穿 no_fly 多边形（clearance=0） | 过渡直线硬墙净距检查 → need_wall 画墙 |
| zigzag13 | 大跨度膨胀墙切角 0.71×cell 不足 | span>2.5° 时膨胀补 0.71×cell（3→4 格）+ 距离 <2500km |
| zigzag17 | 多边形尖角顶点墙角钝化 | span>2.5° 膨胀格数 +1 兜底尖角偏差 |
| zigzag18 | FMM 90° 楼梯角 fallback 92° 急转弯 | Theta\* fallback `arc_transition` 插圆弧过渡点 |

**地形依赖检测**：
- `cases/` 中 terrain.path 指向 `data/east_asia_7p5as.arpack`（发布版默认地形；
  2026-08-10 起 china_dem_l12 已退出测试流程；数据文件已 gitignore）；
- 运行期：文件存在 → 改写 path 为绝对路径（真实地形）；缺失 → terrain.source=none 合成平面（覆盖不到真实地形 bug，但保证无数据环境仍可跑）。

**用例目录**：`cli/tests/regression/cases/*.json`（34 个，遍历发现自动纳入）——13 个基础反馈用例（moved_rz / new_rz / real_bad / real_rz / real_rz_1500 / real_rz_low / real_rz_polygon / rz_a_mountain / rz_b_plain / test_trap / test_twin / test_twin7 / top_vs_bottom_rz）+ 锯齿系列（zigzag2 / zigzag3 / zigzag4 / zigzag9 / zigzag10 / zigzag11 / zigzag12 / zigzag13 / zigzag14 / zigzag15 / zigzag16 / zigzag17 / zigzag18 / zigzag_nf2 / zigzag_rz）+ 主管输入原始 JSON（zigzag25_2v_radar / zz30_input / zz31_input / rz_poly_profile / rz_poly_wall_detour 等，2026-08-12 起逐轮追加）——**新增用例：放 JSON 进 cases/ 即自动纳入**；zigzag19–38 其余回归在 solver.rs 内单测（真实地形才跑，见 07 文档第 6 节）。

## 9. 空洞/掩膜专项验证

- **空洞语义**：LOS 空洞视为不遮挡 → blocked 5.5% vs 全有效 19.6%（低估遮挡 = 非保守侧）；代价场空洞墙把有效区切多岛 → 可达率 33/100；
- **NODATA 5x 复核**：南海区 NoData 55%——5x 高代价通行可达率 100% vs inf 禁行 45%——保守高代价保持可用性；
- **掩膜 3 态**：GMTED2010 + mask_10as 全球采样 Land 29.5% / Water 70.1% / Lake 0.5%（吻合理论 ~29.2%）；定点北京 Land(52.1m) / 太平洋 Water / 青海湖 Lake(3194m)；掩膜加速海洋采样（247µs vs 1172µs 随机）。
