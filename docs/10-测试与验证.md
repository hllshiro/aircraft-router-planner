## 1. 测试分层

| 层 | 载体 | 覆盖 |
|----|------|------|

## 2. 崩溃/退化输入套件（B9 显式验收项）

**十四轮终裁**："绝对不能崩溃"必须有可验证抓手。入 CI **一票否决**。

覆盖范围：

| 模块 | 用例 |
|------|------|
| config | 空输入、null、类型错误、缺必填、NaN 坐标、超界纬度、畸形 JSON |
| coord | NaN/极端反算 |
| terrain | 垃圾字节、截断、零维度、畸形 ARPK1/掩膜 |
| spatial | 空树 + NaN 查询 |
| costfield | 退化网格、不可达回溯 |
| builtin | 哈希/版本/截断/魔数不符 → fail-fast（不 panic） |
| solver | 退化输入端到端 |

## 3. 回归套件—— 历史 bug 防复发

**背景**：历史上主管反馈 bug 的原始输入（锯齿/直穿 restricted/禁飞区陷阱等）。

**回归语义**：
1. 每个输入 parse + validate + solve 全过（不 panic、不 Err）
2. 输出路径逐点不穿任何 zone

**强断言防锯齿复发**：

| 用例 | 断言 | 防回归的修复 |
|------|------|--------------|
| zigzag11 | <30 点 + 无 smoothing_failed | Theta\* 首跳入口航向约束 |
| zigzag12 | 剖面过渡直线不穿 no_fly | 过渡直线硬墙净距检查 |
| zigzag13 | 膨胀墙补足 | span>2.5° 膨胀补 0.71×cell |
| zigzag17 | 多边形尖角墙角钝化 | 膨胀格数 +1 兜底 |
| zigzag18 | FMM 楼梯角 fallback | arc_transition 插圆弧 |

**用例目录**：`src/cli/tests/regression/cases/*.json`（34 个，自动发现纳入）

## 9. 测试命令

```bash
cargo test --workspace          # 全部单元 + 集成 + 崩溃套件
cargo test -p arpcli --test crash_suite   # 崩溃套件单独跑
cargo test -p arpcli --test regress_phase0 # 回归套件
cargo test -p arpcli --test determinism    # 确定性
cargo bench -p phase0           # Phase 0 基准
cargo bench -p arpcli --bench b_load_decompress  # 内置格式加载
```

**默认全量门禁**（`scripts/check.sh`）：构建 + lib 单元 + crash + determinism + regress 共 4 套件。
