## 2. 依赖版本锁定

| crate | 锁定 | 依据 |
|-------|------|------|
| rand | ^0.10 | geo 0.33.1 → rand ^0.10.0 |
| rstar | ^0.12 | geo 0.33.1 → rstar ^0.12.0 |

排查方法：`cargo tree -d`（重复依赖）、`cargo tree -e normal`（C 依赖）

## 3. 静态编译红线

交付形态：**单二进制可执行文件（Linux musl / Windows MSVC 静态）**。

四条红线：
1. **nalgebra 仅默认特性，禁用 blas**
2. **geo 不启用 proj feature**
3. **flate2 保持默认 rust_backend**
4. **ruzstd 为纯 Rust**

CI 用 `cargo tree -e normal` 断言零 C 依赖 + musl target 构建一票否决。

## 4. 确定性构建

```toml
# .cargo/config.toml
[target.x86_64-unknown-linux-gnu]
rustflags = ["-C", "target-feature=-fma"]

[target.x86_64-pc-windows-msvc]
rustflags = ["-C", "target-feature=+crt-static", "-C", "target-feature=-fma"]
```

- 禁用 FMA（跨平台逐位一致）
- Windows MSVC 静态 CRT（不依赖 VCRUNTIME140.dll）
- 禁止 `target-cpu=native`

## 5. 交付形态

| 平台 | 格式 | 说明 |
|------|------|------|
| Linux x86_64 | musl 静态二进制 | 无 glibc 依赖 |
| Windows x86_64 | MSVC 静态 CRT | 无 VCRUNTIME140.dll 依赖 |
| 数据包 | arpack + mask | 默认地形/掩膜文件 |

## 6. 构建/运行命令

```bash
# 构建
pnpm cli:build                # cargo build --release -p arpcli

# 测试
pnpm test                     # cargo test --lib
pnpm test:all                 # cargo test --workspace

# 门禁检查
pnpm check                    # 构建 + 全套回归 + 静态红线
pnpm check:quick              # 快速检查（跳过回归套件）

# 运行
arpcli plan --file input.json --out output.json

# 帮助
arpcli
arpcli help
```

## 7. CI 流水线

- **push/PR**：`cargo check --workspace --all-targets` + 依赖红线（不跑测试）
- **workflow_dispatch**：手动触发测试矩阵
- **release**：`v*` tag 触发，交叉编译 windows/linux × amd64/arm64 四产物

## 8. 门禁检查

```bash
pnpm check [--quick] [--with-compare]
```

等价于 `node scripts/check.js`，选项：

- 默认：构建 + lib 单元 + crash + determinism + regress（4 套件）
- `--quick`：跳过回归套件（`pnpm check:quick`）
- `--with-compare`：额外跑 field_build_compare（~7min，只在改动 builtin.rs 时用）
