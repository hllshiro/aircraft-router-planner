## 3. 静态编译红线（3.2.1）

交付形态：**单二进制可执行文件（Linux musl / Windows MSVC 静态）**。四条红线：

1. **nalgebra 仅默认特性，禁用 blas**（会拉 openblas-src C/Fortran）；
2. **geo 不启用 proj feature**（PROJ C 库绑定；投影自研：自定义 TM 约 50 行 + UTM/GK3 同族参数化公式）；
3. **flate2 保持默认 rust_backend**（不启用 zlib/zlib-ng-compat）；
4. **ruzstd（Zstd 解码）为纯 Rust**（内置地形数据运行时解码；压缩仅开发期 zstd CLI 完成）。

**CI 一票否决**：`cargo tree -e normal` 断言零 C 依赖（openblas/zlib/curl/proj/gdal/pcre/ssl 零匹配）+ `x86_64-unknown-linux-musl` release 构建通过。

## 4. 确定性构建配置（.cargo/config.toml）

```toml
[build]
rustflags = ["-C", "target-feature=-fma"]           # 禁 FMA 收缩（跨平台位差主源）

[target.x86_64-pc-windows-msvc]
rustflags = ["-C", "target-feature=-fma", "-C", "target-feature=+crt-static"]  # MSVC 静态 CRT

[target.x86_64-unknown-linux-musl]
rustflags = ["-C", "target-feature=-fma"]
```

**确定性约定（5.2）**：
- 编译期 IEEE754 严格语义（默认即严格，不引入 fast-math）；
- 显式禁 FMA（`-C target-feature=-fma` 或 `-ffp-contract=off` 等价）；
- target-cpu 保持默认 generic（不设 native，native 随机器变化破坏跨平台复现）；
- 并行归约顺序确定性由代码层保证（BTreeMap / 固定索引分块 reduce，禁止 fold 无序合并）。

**Windows MSVC 静态验证（主管决策 2026-08-05）**：`+crt-static` 后 exe 不再依赖 VCRUNTIME140.dll；`cli/check_pe_deps.py` 验证 exe 仅依赖系统 DLL。

## 5. 交付形态

| 项 | 内容 |
|----|------|

| install/ 布局 | `install/` 整个目录即安装包（gitignore）：`aircraft-router-planner-cli.exe` + `data/`（默认地形/掩膜）+ `demo/`（独立可运行子包，可删）——复制到目标机即用 |

## 6. 构建命令

```bash
# 核心 CLI
cargo build --release -p aircraft-router-planner-cli

# Demo 后端
cargo build --release -p demo-server

# 全部（含 phase0）
cargo build --release --workspace

# 测试
cargo test --workspace

# 交叉编译（Phase 5 CI 落地）
cargo build --release --target x86_64-unknown-linux-musl -p aircraft-router-planner-cli

# 静态依赖审计
cargo tree -e normal | findstr /i "openblas zlib curl proj gdal pcre ssl"
```

**CLI 参数（clap）**：

| 参数 | 说明 |
|------|------|
| `--input <FILE>` | 任务 JSON（缺省读 stdin） |
| `--output <FILE>` | 结果 JSON（缺省写 stdout） |
| `--seed <u64>` | 随机种子（确定性） |
| `--config <FILE>` | 默认参数表覆盖 |
| `--terrain <FILE>` | 地形文件（ARPK1；缺省用输入 terrain.path；none 源不加载） |
| `--grid <usize>` | 粗网格分辨率（默认 256；任务区域自适应） |

## 7. 运行示例

```bash
# 最小输入（stdin 管道）
echo '{"schema_version":"0.20","mission":{"start":{"lon":115.0,"lat":39.0,"alt_m":3000},"target":{"lon":116.5,"lat":39.9,"alt_m":3000}}}' | aircraft-router-planner-cli

# 文件输入 + 输出 + 指定地形
aircraft-router-planner-cli --input task.json --output result.json --terrain data/east_asia_7p5as.arpack

# 指定粗网格 512
aircraft-router-planner-cli --grid 512 < task.json
```

## 9. 常见坑位备忘

- `rand` 勿降 0.8、`rstar` 勿升 0.13（geo 0.33.1 锁死）——否则双大版本共存（体积 + API 分裂）；
- `geotiff`/`dted2` 升级需单独评审（breaking 预告 / 维护停滞）；
- 构建工具链需 ≥ 1.85（2024 edition 前提）；
- 静态检查：`cargo tree -d` 查重复依赖，`cargo tree -e normal` 查 C 依赖。
