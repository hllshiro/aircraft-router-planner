# 08 — 地形数据源

> 设计依据：技术方案 4.2.2（高程基准）、4.2.5（内置地形数据契约）、4.3（TerrainSource trait）

## 1. 架构总览

```
TerrainSource trait（统一查询接口）
   ├── BuiltinSource    —— 自建紧凑格式 ARPK1（16-bit + 分块差分 + Zstd）
   ├── SrtmSource       —— SRTM/HGT 裸 16-bit 大端网格
   ├── GeoTiffSource    —— GeoTIFF
   ├── DtedSource       —— DTED/DTED2
   └── Terrain (memory) —— 内存网格（测试/原型）
GeoMask + MaskedSource   —— GSHHG 海陆掩膜包装
```

**按输入路径选择 reader**：

| 扩展名 | reader |
|--------|--------|
| `.hgt` | SrtmSource |
| `.tif` / `.tiff` | GeoTiffSource |
| `.dt0` / `.dt1` / `.dt2` | DtedSource |
| `.zstd` / `.arpack` | BuiltinSource |

**solver 外部格式直读**：`TerrainHandle` 按扩展名分派，外部格式不做转换。

**地形数据索引**：`data/index.yaml` 定义可用地形/掩膜候选项，输入 JSON 使用索引 id。

```yaml
arpacks:
  - id: east_asia
    desc: "东亚 7.5角秒地形"
    file: east_asia_7p5as.arpack
masks:
  - id: east_asia
    desc: "东亚海陆掩膜"
    file: east_asia_7p5as.mask
```

## 2. TerrainSource trait

```rust
pub trait TerrainSource: Send + Sync {
    fn height_at(&self, lon: f64, lat: f64) -> Option<f64>;
    fn sample_at(&self, lon: f64, lat: f64) -> Sample { ... }
    fn bounds(&self) -> Option<GeoBounds>;
    fn resolution_desc(&self) -> String;
}
```

### 2.1 语义采样结果（Sample）

```rust
pub enum Sample {
    Land(f64),      // 陆地，携带高度
    Water,          // 海洋，高度 0
    Lake(f64),      // 内陆湖，携带湖面高度
    NoData,         // 真缺失
    OutOfBounds,    // 超覆盖范围（高代价通行）
    Forbidden,      // 禁行硬墙（INF 禁行 + LOS 遮挡）
}
```

| 方法 | 语义 |
|------|------|
| `base_cost(nodata_mult)` | Land/Water/Lake → 1.0；NoData/OOB → 5x；Forbidden → INF |
| `los_unblocked()` | Land/Water/Lake → true；NoData/OOB → true；Forbidden → false |

### 2.2 LOS 遮挡判定

沿方向等距采样 n 点，任一点：`Land(h)` 且 `z ≤ h` → 遮挡。

## 3. ARPK1 自建紧凑格式

### 3.1 文件布局

```
[0..8)     magic "ARPACK1\0"
[8..288)   定长头（format_version / rows / cols / origin / cell / z_resolution 等）
[288..320) sha256（数据部分）
[320..)    块索引：blocks_x*blocks_y × (offset, len)
           数据块流：每块 = 行内差分 i16（raw 或 zstd）
```

### 3.2 关键常量

| 常量 | 值 | 说明 |
|------|-----|------|
| BLOCK_SIZE | 256 | 块边长 |
| CACHE_MAX_BLOCKS | 2048 | 解压块缓存上限（≈256MB） |

### 3.3 打开与校验

**`open(path)`**：只读头部 + 块索引做结构校验（O(1)），数据区 mmap 虚拟映射。

**`parse(bytes)`**：结构校验 + SHA-256 全量校验。

### 3.4 按需解压 + 有界缓存

- `cell(r, c)`：跨块自动定位 → 缓存命中 → 未命中锁外解压
- 块加载：raw 直接转 i16；zstd 用 ruzstd 解码
- 行内差分还原：`v[i] = v[i-1] + v[i]`
- 缓存 FIFO 淘汰：2048 块上限

### 3.5 采样（双线性插值）

计算网格坐标 → 四邻格 `cell()` → 双线性插值。越界 → None。

### 3.6 转换命令（独立内部工具 arp-convert）

```
arp-convert convert <in> <out.arpack>          # 外部格式 → ARPK1
arp-convert recompress <in.arpack> <out.arpack> # 块压缩重压缩
```

不随核心 CLI 发布，随用随编。

## 4. GSHHG 海陆掩膜

### 4.1 类别语义

| 类别 | 编码 | 语义 |
|------|------|------|
| Sea | 0 | 海洋（海平面高程 0） |
| Land | 1 | 陆地 |
| Lake | 2 | 内陆湖 |

### 4.2 查询与包装

- `class_at(lon, lat)`：行 RLE 段查找
- `MaskedSource<T>`：包装任意 TerrainSource，按掩膜分类映射 `sample_at`

### 4.3 数据来源与处理流程

**原始数据**：GSHHG 2.3.7（Global Self-consistent Hierarchical High-resolution Geography）

- 来源：https://www.soest.hawaii.edu/pwessel/gshhg/
- 许可：Lesser GNU Public License v3
- 包含：全球海岸线（`gshhs_f.b` / `gshhs_h.b`）、河流（`wdb_rivers_f.b`）

**处理流程**：

1. 原始二进制文件（`.b`）由预处理脚本转换为掩膜格式
2. 掩膜文件（`.mask`）采用 V2 RLE 行段存储，详见 `src/cli/src/terrain/mask.rs`
3. 脚本路径：`phase0/scripts/gshhg_mask.py`（历史参考）

**当前状态**：原始 GSHHG 数据已移除，仅保留预处理后的 `.mask` 文件。如需重新生成掩膜，需重新下载原始数据集。

## 5. SRTM/HGT

- 读取 `.hgt` 裸 16-bit 大端网格
- 文件名解析 `N39E116.hgt` → (lat, lon)
- 单文件覆盖 1°×1°

### 目录形态

片级 LRU（8 片 ≈ 208MB），跨片边界采样。

## 6. GeoTIFF

- `tiff` crate（pure Rust）读取
- **两级策略**：chunk 数 ≤ 64 → 全量内存；超过 → chunk 按需解压 + LRU
- 地理参考自解析：ModelTiepoint + ModelPixelScale
- north-up 方向判定

## 7. DTED/DTED2

- `dted2` crate 读取
- 目录形态：O(1) 只读 UHL 建片索引 + 片级 LRU
