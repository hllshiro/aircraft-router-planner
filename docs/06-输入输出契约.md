# 02 — 输入输出契约与数据校验

> 代码位置：`src/cli/src/config.rs`（1449 行）、`src/cli/src/error.rs`（141 行）、`src/cli/src/main.rs`（193 行）
> 设计依据：技术方案 4.2.1（默认参数表/无解出口/status 契约）、4.5（输入-约束-校验传导矩阵）、十三轮共识（多机契约/InputValidator/压制后距离输入化）

## 1. 总览

CLI 采用 **文件 I/O** 形态：`arpcli plan --file <file> --out <path>`（路径规划）从文件读任务 JSON → 文件输出结果 JSON。help 风格：`arpcli` / `arpcli help`（不使用 `--help`）。所有字段 `deny_unknown_fields`（未知字段 = 畸形）。

```
main.rs 流程：
  read_input → Input::from_json_str（畸形 → input_invalid: malformed_json）
  → config::validate（InputValidator：退化输入 → input_invalid + 原因码）
  → solver::solve（成功 → Output::success；解算层错误 → input_invalid）
```

**status 四态契约**（输出 JSON 顶层）：

| status | 含义 | 触发 |
|--------|------|------|
| `success` | 规划成功（含每机 `planned` / `no_solution` / `degraded`） | 正常完成 |
| `degraded_timeout` | 超时返回可用结果（warm best-so-far） | 预算耗尽（当前 solver 未显式触发，机制就绪） |
| `no_solution` | 确定性无解 + 原因码 | 全出口链耗尽 |
| `input_invalid` | 非法/退化输入 + 原因码（**不进入算法**） | 解析/校验层拦截 |

> 关键语义：`no_solution` 不是失败，是确定性结论；非零退出（exit 2）只留给硬故障（IO/内部错误）；超时/无解不触发非零退出。

## 2. 输入契约（Input）

顶层结构（v0.21 契约拍平，无 `mission` 包裹层；`deny_unknown_fields` 拒绝旧键 `mission`/顶层 `start`/`target`/`vehicles`/`weapons`/`zone_type`）：

```rust
pub struct Input {
    pub aircraft: Vec<AircraftInput>,      // 飞行器数组（必填非空；空数组 → missing_aircraft）
    pub red_forces: RedForces,             // 红方部署（radars）
    pub zones: Vec<Zone>,                  // 统一区域数组（每个 zone 必须提供 zone_type 字段）
    pub terrain: TerrainConfig,            // 地形源配置
    pub parameters: ParamsOverride,        // 默认参数表覆盖
}
```

**最小输入 JSON 示例**（单机，起终点逐机显式）：

```json
{
  "aircraft": [
    {
      "id": "a1",
      "start":  { "lon": 115.0, "lat": 39.0, "alt_m": 3000 },
      "target": { "lon": 116.5, "lat": 39.9, "alt_m": 3000 }
    }
  ]
}
```

**Waypoint**：`{ lon, lat, alt_m }`（经纬度度 + 高程米；高度一律 MSL）。构造时经 `Geo::new` 校验（非法经纬度/NaN/Inf → `input_invalid: illegal_coordinate`）。

### 2.1 顶层 Input 字段

- `aircraft` **必填非空**：字段缺失 → `malformed_json`（缺必填）；**空数组 → `input_invalid: missing_aircraft`**（新原因码，validator 拦截）。
- 其余字段 `#[serde(default)]`，可省略。

### 2.4 Zone（禁飞/限飞/障碍物）

```rust
pub struct Zone {

```

- **统一 zones 数组**（v0.21 第三波）：旧三数组（`no_fly_zones` / `restricted_zones` / `obstacles`）合并为 `zones[]`，每个 zone 必须提供 `zone_type` 字段（no_fly / restricted / obstacle）。
- `Zone::is_wall()`：NoFly/Obstacle 为**全高度水平墙**（FMM 代价场 INF）；Restricted 为高度层禁入（区间外可穿越，不画墙）。
- **禁飞区无高度范围**（2026-08-12 主管定案）：NoFly/Obstacle 全高度禁入，`alt_min_m`/`alt_max_m` 可省略（省略 = 全高度）；**Restricted 必须提供** `[alt_min, alt_max]`（`alt_min < alt_max`，validator 强制，缺失/倒置 → `out_of_bounds`）。
- **高度一律 MSL**（限飞区高度语义，见 4.2.2）。

### 2.6 飞行器武器（Weapon，2026-08-12 主管定案：类型 + 射程；2026-08-19 移入飞行器）

```rust
pub struct Weapon {
    pub weapon_type: WeaponType,         // aam / agm / bomb；必填（出现即启用）
    pub range_km: Option<[f64; 2]>,      // 射程 [Rmin, Rmax] km；缺省 = 按类型默认值
    pub envelope: Option<LaunchEnvelope>,// 发射包线（已消费，P7 2026-08-12）
}

pub enum WeaponType { Aam, Agm, Bomb }   // 空空导弹 / 空地导弹 / 航空炸弹
```

- **武器移入飞行器**（v0.21 第二波）：删除顶层 `weapons` 数组与 `weapon_id = "<vehicle_id>_w1"` 拼接约定；武器为 `aircraft[].weapon` 可选字段，**出现即启用**（`weapon_type` 必填，缺失 → `malformed_json`）。
- **武器语义 = 武器类型 + 武器射程**（主管 2026-08-12）：`weapon_type` 三选一（`aam` 空空导弹 / `agm` 空地导弹 / `bomb` 航空炸弹）。
- **射程按类型默认**：`range_km` 缺省时按类型取默认值；显式提供优先。
- `effective_range_km()`：`weapon` 出现 → 显式 `range_km` 或类型默认（aam [5,40] / agm [3,120] / bomb [1,15] km）。
- 校验：显式 `range_km` 必须有限且 `lo < hi`（倒置/非有限 → `out_of_bounds`）。
- **飞行器关联**（P7 2026-08-12）：`aircraft[].weapon` 出现 → 该机目标语义切换为**环带目标集**（FMM 传播到距目标 ∈ [Rmin,Rmax] 环带即停，路径停在进入环带处/Rmax 外边界，不得停在 Rmin 内）；无武器 → 点目标语义（不回归）。

**LaunchEnvelope**：`heading_deg: Option<[f64; 2]>` / `alt_m: Option<[f64; 2]>` / `speed_mps: Option<[f64; 2]>`。

- **发射包线消费语义**（P7 2026-08-12，docs/技术方案 §4.2"冲突时以发射包线优先"）：
  - `heading_deg`：窗口 = 从 lo 顺时针扫到 hi（跨 0° 如 [350,10] = 20° 宽）；终端 heading 下放平滑级（末段 Dubins 终端 pose = 窗口中心）；交付前终检末段航向 ∈ 窗口，不满足 → `no_solution`（`geometrically_impossible` + degradation "launch envelope not satisfied"）。
  - `alt_m`：终点目标高度 clamp 到窗口（垂直剖面终点优先包线）；终检终点高度 ∈ 窗口，不满足 → `no_solution`。
  - `speed_mps`：巡航速度（`maximum_speed_mps`）∈ 窗口；不满足 → 软校验（degradation 告警，规划不可调速度，不阻断交付）。

**默认射程表（2026-08-12 定案：类型 + 按类型默认射程；v0.21 起无 weapon_id，武器随飞行器）**：

| weapon_type | range_km（默认） |
|-------------|------------------|
| aam | [5, 40] |
| agm | [3, 120] |
| bomb | [1, 15] |

## 3. 输出契约（Output）

```rust
pub struct Output {
    pub status: String,                // success / degraded_timeout / no_solution / input_invalid
    pub error: Option<ErrorBody>,      // status != success 时携带
    pub elapsed_ms: Option<u64>,
    pub aircraft: Vec<AircraftOutput>, // 每机结果（原 vehicles）
    pub stats: Stats,                  // 统计
}

pub struct AircraftOutput {
    pub id: String,
    pub status: String,                // planned / no_solution / degraded
    pub path: Vec<PathPoint>,          // 航路点（x=经度, y=纬度, alt_m=MSL 米）
    pub distance_m: f64,
    pub warnings: Vec<String>,         // 复验警告（smoothing_failed / radar: ...）
}

pub struct Stats {
    pub fmm_ms: f64,                   // FMM 传播累计耗时
    pub los_checks: u64,               // LOS 检查次数（当前 0，静态代价场未计数）
    pub degradations: Vec<String>,     // 降级/回落记录（供下游签收）
}
```

**坐标口径（主管决策 2026-08-05）**：输入输出坐标点均为经纬高定义，`x = 经度（度，WGS84）`、`y = 纬度（度）`、`alt_m = MSL 几何高度（米）`。

> **垂直剖面语义（2026-08-12 主管 demo 轨迹倾斜修复；2026-08-13 P8 M2 多锚点扩展；2026-08-14 三反起终点贴地修订）**：输出 `PathPoint.alt_m` 不再恒等于巡航高度——起终点高度不同（`aircraft[].start.alt_m` ≠ `aircraft[].target.alt_m`）时，路径高度按累计水平距离从起点高度线性过渡到目标高度（轨迹呈现爬升/下降）；**必经点 `mid_waypoints[].alt_m` 为分段锚点**（P8 M2：起→必经点→终点按段内比例插值；缺省同起点高度 = 无效果，行为同单段线性过渡）。规则：
> - **起终点贴地（2026-08-14 三反）**：起终点高度 = 用户设定硬约束（起飞/降落场景贴地合理，不加净空）；仅当低于当地地面 MSL 时物理保底抬升到地面（warnings `"start/target altitude below terrain: raised ..."`）；**不因中间地形被抬升**——中间段由方案 B 自动锚点爬升（撞山区段最高地形点 → 自动中间锚点 `(lon, lat, 抬升高度)`，`apply_vertical_profile` 据此缓爬升/缓下降）；
> - 起终点同高 → 行为与既往一致（恒为巡航/抬升高度，受限区剖面语义不变）；
> - **剖面段保持**：受限区底部穿行/顶部绕飞剖面（高度显著偏离巡航高度的路径段）不参与插值，保持 `build_restricted_profiles` 生成的剖面语义；
> - **抬升场景**（地形要求巡航高度抬升）：巡航段高度不低于抬升后巡航高度（既有地形安全裁决），仅终点可继续爬升至目标高度；抬升时起终点保持用户高度（`terrain_alt_raised` warnings 显式提示）；
> - **净空语义**：中间段（距起终点 1km 外巡航段）路径点高度 ≥ 地形 + 净空（100m）保底；**起终点段（1km 内起飞/降落段）允许净空 <100 但不穿地**（2026-08-14：贴地爬升/下降按 15° 平滑线插点，min(地形+净空, 端点+tan(15°)×距离) 且不低于地形）；
> - 每机目标高度 = `aircraft[].target.alt_m`（逐机显式）；
> - Demo 前端：飞行器表单提供**武器类型下拉框**（不启用/空空导弹 AAM/空地导弹 AGM/航空炸弹）与**射程 Rmin/Rmax 输入框**（缺省按类型默认：AAM [5,40]、AGM [3,120]、Bomb [1,15] km），序列化到 `aircraft[].weapon`（出现即启用）。

## 4. 错误体与错误码（error.rs）

```rust
pub enum AppError {
```

**InputInvalidReason（原因码，snake_case）**：

| 原因码 | 触发场景 |
|--------|---------|
| `malformed_json` | JSON 语法/结构畸形、类型错误、缺必填、未知字段（含旧契约键 `mission`/顶层 `start`/`target`/`vehicles`/`weapons`/`zone_type`） |
| `illegal_coordinate` | 经纬度越界 / NaN / Inf |
| `out_of_bounds` | 半径非正、速度越界、限飞区高度区间倒置 |
| `degenerate_start_equals_target` | A 与 B 相同或间距 < 100m |
| `target_in_no_fly` | 目标（或飞行器起点）落在禁飞区 |
| `mid_waypoint_in_no_fly` | 必经点落在禁飞区（必经点不可绕行 → fail-fast，P5） |
| `radar_overlap_no_fly` | 雷达位置在禁飞多边形内 |
| `terrain_holes_remain` | 地形空洞残留（预留，当前由数据源语义处理） |
| `vehicle_params_inconsistent` | 重复飞行器 ID / 速度范围倒置 / A6 物理自洽失败 |
| `missing_aircraft` | `aircraft` 数组为空（逐机显式契约下无任务可规划） |

## 5. InputValidator（config::validate）

入口防线：**畸形/退化输入在进入算法前拦截**，输出专属 `input_invalid` + 原因码。

校验顺序：

1. **aircraft 空数组** → `missing_aircraft`（新原因码；逐机显式契约下无任务可规划）；
2. **逐机（aircraft 循环）**：
   - 重复 `id` → `vehicle_params_inconsistent`；
   - `validate_aircraft`（profile）：最大速度 ∈ [1, 2000] m/s；最大转弯角速率 ∈ [0.1, 360] °/s；最大爬升率 ∈ [0.1, 500] m/s；最大高度 ∈ [100, 30000] m；显式 `weapon.range_km` 有限且 `lo < hi` → 否则 `out_of_bounds`；
   - 逐机 `start`/`target` `to_geo()` 校验合法坐标（`illegal_coordinate`）；`start ↔ target` 间距 < 100m → `degenerate_start_equals_target`；
   - 逐机起点在禁飞区 → `target_in_no_fly`；逐机目标在禁飞区 → `target_in_no_fly`；逐机必经点在禁飞区 → `mid_waypoint_in_no_fly`；
3. **雷达 ∩ 禁飞区**：雷达位置在禁飞多边形内 → `radar_overlap_no_fly`；`radius_km ≤ 0` → `out_of_bounds`；
4. **限飞区高度区间**：Restricted 必须提供 `[alt_min, alt_max]`（有限且 lo < hi），缺失/倒置 → `out_of_bounds`（NoFly/Obstacle 全高度禁入，不要求 alt）；
5. **参数覆盖数值域**：不再 fail-fast（2026-08-05 决策），由 merge 回落默认并记录 degradations。

### 5.1 几何工具（config.rs 内置）

| 函数 | 说明 |
|------|------|
| `zone_contains(z, p)` | 点是否在 Zone 内（圆：测地距离 ≤ 半径；多边形：射线法经纬度平面近似） |
| `zone_contains_at(z, p, alt_m)` | 水平 + MSL 高度区间判定 |
| `point_in_polygon` | 射线法（ray casting）点在多边形内 |
| `zone_segment_clearance_km` | 线段到 Zone 水平最小净距（km）。0 = 段穿入或贴边界；多边形端点在内为 0，否则取段到每条边的最近距离；圆形 = 段到圆心最近距离 − 半径 |
| `pt_seg_dist_km` / `seg_seg_dist_km` / `segs_intersect_plane` | 平面近似距离/相交判定（经度按 cos 缩放） |

> `zone_segment_clearance_km` 是 **Theta\* 去锯齿与复验的几何精确判定核心**（主管 2026-08-06：绕飞太贴边 → 考虑飞机机动留转弯空间），替代了早期"等距 16 点采样"方案（采样点可能恰好全落在多边形外部 → 拉直穿过禁飞区内部的漏判）。

## 6. 默认参数表（DefaultParams）

编译期常量，输入未提供时使用；**多数仍为占位值（p_cross 等），Phase 0 校准后才生效**（四轮共识）。`detection_curve`/`base_p`（Swerling I）已于 2026-08-13 标定，见 06 威胁模型。要点：

| 参数 | 默认值 | 说明 |
|------|--------|------|
