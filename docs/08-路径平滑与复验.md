# 08 — 路径平滑与全链复验

> 代码位置：`cli/src/smooth.rs`（1410 行）、`cli/src/path.rs`（161 行）、`cli/src/dubins.rs`（264 行）
> 设计依据：技术方案 Phase 3（输出美化链 + 九轮链序修正 + 十轮复验清单 + 十一轮回退语义）、Phase 4 M4（机型分流参数派生）

## 1. 设计定位

Phase 3 输出美化链——**纯几何后处理**：输入折线路径（经纬度+高度），输出平滑路径。

**默认链序（九轮共识）**：Theta\* 去锯齿 → Dubins/样条拟合 → 贪心抽稀 → 弦高/运动学复验。

**优先级（九轮共识）**：安全（不撞山/不越禁飞）> 运动学约束（机动可飞）> 美化（平滑/抽稀）。

**回退语义（十一轮共识）**：任一复验失败回退上一策略环节；全链失败 → 交付**美化前原始折线** + 显式告警 `smoothing_failed`（宁丑勿违，不静默交付违规路径）。

### 3.1 机型分流参数派生（smooth_options_for，Phase 4 M4）

```
v = cruise_speed_mps → speed_range 中值 → 机型默认（固定翼 250 / 旋翼机 100 m/s）
φ_max = max_bank_deg → 默认 30°
r_phys = v²/(9.81 × tan φ_max)          # A6 物理下限
base_r = min_turn_radius_m → 机型默认（固定翼 5000 / 旋翼机 0 m）
turn_radius = 旋翼机: base_r（r→0 合法，不钳）
              固定翼: max(base_r, r_phys)   # 输入更小值也钳到物理下限
max_climb = max_climb_angle_deg → 默认 15°
```

**物理意义**：固定翼 turn_radius 恒 ≥ 物理下限 → A6 自洽恒过；旋翼机悬停/原地转向（r→0）为合法机动，不钳。

## 4. 基础平滑算法

### 4.1 Theta\* 去锯齿（theta_star_smooth）

LOS 捷径简化——贪心跳点：

```
锚点 i 起，从路径末尾向前找第一个 check 通过的跳跃点 j（i,j 间直连合法）
保 i、j，删中间点；max_turn_deg 约束相邻航段转角（防弧线拉直成 61°+ 折线）
复杂度 O(n²)（点列短，粗层走廊点数百级可接受）
```

### 4.2 Chaikin 角切割（chaikin_smooth）

每段取 1/4、3/4 插值点，保持端点；1-2 轮即够（过多收敛到线段本身）。

### 4.3 Catmull-Rom 样条（catmull_rom_spline）

每段插 samples_per_seg 点，首末段端点复制（自然边界）。**对"绕行弧线"输出曲率 ≈ 绕行半径的平滑样条，复验自然通过；对"锯齿直穿"样条曲率小 → 半径复验失败 → 回退 Dubins/直线替代（正确语义）**。

### 4.4 贪心双指针抽稀（greedy_simplify）

锚点 i，指针 j 从末尾向前找最大跳跃——(i,j) 内全部点相对线段 [i,j] 的弦高 ≤ 容差则保 j 删中间，否则 j 前移。保留首末点。O(n²)。

### 4.5 局部等距投影（LocalProjection）

以中点为中心：`to_xy: ((lon−clon)×k×111320, (lat−clat)×111320)`，`k = cos(clat).max(1e-6)`。用于平面计算（Dubins 拟合/航向/外接圆）。

## 5. Dubins 路径基元（dubins.rs）

**CSC 四类型（LSL / RSR / LSR / RSL）最短路径解析求解**：

- 坐标系 y 向上、航向角逆时针；L 圆心 = p + R·(−sinθ, cosθ)，R 圆心 = p + R·(sinθ, −cosθ)；
- 同向圆（L-L/R-R）用外切线（要求 d ≥ 2R）；异向圆（L-R/R-L）用内切线（d ≥ 2R）；
- 每种类型两个候选切线侧，取总长最小；
- 弧角按转向类型计算（L 逆时针 / R 顺时针）；
- **简化：CCC 类型（RLR/LRL）未实现**——d < 2R 退化情况判无解（成功率测量点，正式实现补 CCC）。

```rust
pub struct DubinsPath { t1, t2, a1, straight, a2, c1, c2, n1, r }
pub fn dubins_path(p0, th0, p1, th1, r) -> Option<DubinsPath>  // 无解 → None，不 panic
pub fn dubins_shortest_len(...) -> Option<f64>
pub fn dubins_success_rate(samples, r) -> (ok, total, avg_len)
```

**防御**：r ≤ 0 / 非有限输入 → None；同点同向 → 零长度路径；切点航向连续性校验（1e-6 容差）。

### 5.1 Dubins 拟合（dubins_fit，smooth.rs）

- 首末 pose：显式 heading 或首末段航向（真北 → 平面角：`hd·rad − π/2`）；
- 平面 = LocalProjection（首末中点）；高度沿原折线插值（`height_on_polyline`——**高程剖面独立插值**，爬升角由复验检查）；
- 无解 → None（回退链继续）。

## 6. 全链复验器（verify_path）—— 十轮复验清单

```rust
pub struct VerifyContext<'a> {
    pub terrain: Option<&'a dyn TerrainSource>,
    pub nofly: Option<&'a CircleIndex>,          // 旧快速路径（仅水平圆）
    pub zones: Option<&'a [Zone]>,               // M2 完整语义（提供时优先于 nofly）
    pub threat: Option<&'a dyn ThreatModel>,     // 雷达软告警
    pub zone_inflation_m: f64,                   // 硬墙水平膨胀距离（0 = 不膨胀）
}
```

**复验清单**：

| 检查项 | 规则 | 机型 |
|--------|------|------|
| 航向连续性 + 转角 | 相邻段航向差 ≤ max_turn_deg | 仅固定翼 |
| 转弯半径 | 三点外接圆半径 ≥ turn_radius_m × 0.99 | 仅固定翼 |
| 爬升角 | 段高度差/水平距离 ≤ tan(max_climb_deg) | 仅固定翼 |
| 地形净空 | Land: alt ≥ h + clearance；Water/Lake: alt ≥ clearance；NoData: **保守不通过** + warning；OOB: 不通过 | 两机型 |
| 禁飞/限飞包含（A4/A5） | 硬墙：段净距 < inflation 拒绝（几何精确）；Restricted：解析二次方程求段-圆相交区间 [t1,t2]，区间内 5 点采样高度判定（浅穿不漏检） | 两机型 |
| 弦高（几何） | 相对美化前参考路径逐点最小距离 ≤ chord_tol_m | 两机型 |
| A6 物理自洽 | turn_radius ≥ phys_min_radius_m（参数化，Phase 4 接入） | 仅固定翼 |
| 雷达威胁（软） | cumulative_p > P_cross → warning（不阻断平滑，degradation 记录） | 两机型 |

> **Restricted 几何精确判定**（2026-08-06 new_rz 教训）：等距采样会漏掉浅穿/短弦（段贴圆擦过时采样点可能全在圆外），改为解析二次方程求相交区间再采样高度，浅穿 0.5km、弦 8.9km 也能检出。

**采样密度**：每段等距 `verify_seg_samples`（默认 8）点（段内最坏情况：端点+中点+加密）。

**机型分支（九轮共识）**：旋翼机跳过固定翼运动学硬拦（悬停原地转向/垂直机动在位置空间表现为急转/陡爬升，是**合法航路**，不得误判）；净空/禁飞/弦高对两机型一律硬约束。

## 7. 平滑器策略链（Smoother trait + 回退语义）

```rust
pub trait Smoother { fn name(&self) -> &str; fn smooth(&self, path: &Path) -> Option<Path>; }
```

策略实现：`ThetaStarSmoother` / `DubinsSmoother` / `CatmullRomSmoother` / `GreedySimplifySmoother`。

**默认链（default_chain）**：
- 固定翼：Theta\* 去锯齿（max_turn 约束）→ Catmull-Rom（16 点/段）→ Dubins 拟合 → 贪心抽稀；
- 旋翼机：Theta\* → 贪心抽稀（**不含 Dubins 全局拟合**——圆弧拟合会拉直/破坏悬停转向点；尖角由机型感知复验放行）。

**执行与回退（smooth_path_chain）**：

```
执行链记录每阶段 (name, path)
从链末向前回退：第一个 verify 通过的阶段即交付
  - dubins 阶段：弦高放宽到 DUBINS_CHORD_TOL_M = 1000m（绕行 L 形圆角 ~0.7km，
    100m 逼近容差会误杀合法绕行）；运动学/地形/禁飞仍严格复验
全部失败 → 交付 input 原始折线 + warning: "smoothing_failed: no smoothed stage
            passed full verification" + 原始折线的复验报告
```

## 9. 与设计的差异/占位

| 项 | 设计 | 当前实现 |
|----|------|---------|
| 终端 pose 下放平滑级 | Dubins/样条以终端 pose（航向/高度/速度）为边界条件 | heading 支持（`with_heading`）；高度/速度包线后续 |
| 平滑器弦高容差标定 | Phase 0 定值 | 100m 保守初值（DUBINS 阶段 1000m 放宽） |
| 3D Dubins | 评估后接入/自研 | 2D Dubins + 高程剖面独立插值（方案风险表已接受降级） |
| CCC Dubins | 完整解 | 未实现（d<2R 判无解） |
| 复验器独立数据路径 | 复验与求解分离 | ✅ 已实现（verify 走全分辨率逐段采样，独立于 FMM 粗层） |
