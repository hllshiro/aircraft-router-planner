# 07 — 求解器与端到端流程

> 代码位置：`cli/src/solver.rs`（4088 行，含测试）
> 设计依据：技术方案 Phase 4 M1–M5（主管 2026-08-05 拍板拆分）、4.2.1（无解出口/默认参数表）、多轮主管现场决策（2026-08-05/06）

## 1. 职责

`solver::solve` 把 Phase 0-3 的库层组件串成主流程：

```
parse → validate（main）→ TerrainSource（ARPK1/无地形）→ 语义代价场
（Land/Water/NoData/NODATA 5x + Zone 硬墙 INF）→ FMM → 回溯 → 平滑链
（Theta* 去锯齿 + 抽稀 + Dubins 拟合 + 复验门）→ VehicleOutput 契约
```

**M1 范围（主管拍板 2026-08-05）**：单机/多机（共享代价场，每机独立 FMM）；Zone 水平几何禁入（高度层 M2）；SmoothOptions 默认值（VehicleProfile 派生 M4）；雷达代价（M3）；target_ref 暂按 mission.target（M5 每机 waypoints）。

## 3. solve() 主流程（分步）

### 步骤 1 — 地形源构建

- `terrain.source = none` → `None`（海拔 0 平面）；
- 否则：`--terrain` 参数 > `terrain.path` 字段；都缺省时**默认地形 = 7.5as 东亚压缩版**（`east_asia_7p5as.arpack`，2026-08-08 拍板，537MB）：
  - 候选路径：exe 同目录 → `data/east_asia_7p5as.arpack`（2026-08-08 数据迁移：项目根 data/ 与 install/data/）→ exe 祖先目录（上溯 3 层）逐个试；
  - 全部不存在 → `AppError::Data`（terrain 声明但文件缺失）。
- **外部格式直读**（2026-08-11，主管拍板）：`TerrainHandle` 按扩展名分派——`arpack/zstd` → `BuiltinSource`（BulkPrefetch 预取），其余 → `open_source` 调 GeoTiff/Dted/Srtm/目录解析库直接读取（`External` / `MaskedExternal` 变体）；不做自动转换（`convert` 子命令保留为显式工具）。

### 步骤 2 — 车辆规格

- `vehicles` 空 → 默认单机 `v1`（mission.start → mission.target，`VehicleProfile::default()` = 固定翼 + 全占位）；
- 否则每机解析：mid_waypoints 经纬度校验；**必经点高度解析为分段锚点**（P8 M2：`Waypoint.alt_m` 生效，缺省 = 起点高度无效果）。

### 步骤 3 — 任务区域（Region）

- 所有起点 + target 的方形包围盒 + 0.15° 缓冲（保证源/目标不贴边）；
- `span_deg = max(经度跨度, 纬度跨度) + 2×0.15`（正方形）。

### 步骤 4 — Zone 集合与索引

- `all_zones = no_fly ∪ restricted ∪ obstacles`；
- `circle_index`：圆形 Zone → `CircleIndex`（平滑复验的快速路径）；
- **墙策略（M2 高度层）**：NoFly/Obstacle → 全高度水平墙（代价场 INF）；Restricted → 不画墙（区间外可穿越），由 Theta\* check + verify 高度判定。

### 步骤 4b — 参数合并 + 禁飞区膨胀距离

- `DefaultParams::default().merge(&input.mission.parameters)`；
- `radar_param_degradations`：无效输入参数回落默认的事实记入 degradations；
- **膨胀距离**（主管 2026-08-06：绕飞太贴边 → 考虑飞机机动）：`inflation_m = max(每机 phys×0.5, clamp[2km, 10km])`，其中 `phys = v²/(g·tanφ)` 物理转弯半径（`smooth_options_for` 派生）。

### 步骤 5 — 语义代价场

```rust
build_semantic_cost_field(grid, grid, |r, c| {
    (lon, lat) = cell_lonlat(r, c)
    若在任一硬墙 Zone 内 → Sample::Forbidden   // NoFly/Obstacle 硬墙（INF，2026-08-11 起由 Forbidden 表达）
    否则 terrain.sample_at(lon, lat)（无地形 → Land(0.0)；数据范围外 → OutOfBounds 同 NoData 5x 通行）
}, 5.0)   // NoData 5x
```

- `cell_lonlat`：格点中心经纬度（`min + (i+0.5)/grid × span`）；
- `lonlat_cell`：经纬度 → 格坐标（clamp 到 [0, grid-1]）。
- **多边形硬墙判定 = 格子矩形与多边形相交**（2026-08-11 修复）：非"格子中心在多边形内"——中心点采样会漏掉多边形尖角/斜边附近 `< 1 格` 的窄带（无格中心命中），FMM 沿漏格贴顶点穿入 → verify 精确几何（`zone_segment_clearance_km`）拒 → 平滑链全败 → **误报 no_solution**（zz_nosolution_case：三角形西顶点窄带 ~30m，256 网格 3.5 列无墙格，FMM 离顶点 84m 穿入）；`rect_intersects_polygon`（任一边相交 / 顶点在矩形内 / 矩形角点在多边形内）保证任何分辨率不漏窄带。圆形 Zone 连续无窄带问题，保持中心点语义。
- **输入点越界不再预检拒绝**（2026-08-11，主管拍板）：起点/终点/必经点落在地形数据范围外 → 走既有空洞/无效数据处理流程（OOB 5x 高代价通行 + 降级警告），不再报 data_error；`Sample::Forbidden` 单独保留 NoFly/Obstacle 硬墙 INF（避免 OOB 语义变更破坏硬墙约束）。

### 步骤 5d — 地形高度过滤（2026-08-10，低空穿山回退修复）

FMM 是 2D 水平传播，**不感知飞行高度 vs 地形**：低空任务（起点 1000m 穿内蒙古高原 2050m+）raw 路径穿山 → Theta\*/verify 全拒 → 回退 734 点网格楼梯（smoothing_failed）。修复（zigzag24）：

- **按本机飞行高度过滤**：代价场把「`Land` + 净空 ≥ `alt + 300m`」格点置 INF → FMM 水平绕山（区别于 restricted 墙膨胀——只对 restricted 墙调用 `apply_inflation_and_band`，**不得因地形存在误调**，否则会膨胀 NoData/OOB 墙挤开 zigzag21 实测路径）；
- 过滤后无解 → **无过滤场探测路径**（区分"真无通道 vs 区域级过度过滤"——青藏高原边缘 3000m 任务原本可走，不得抬升）；
- 探测/过滤路径**撞山**（路径地形 + 净空 ≥ 巡航高度）→ **路径级抬升**到「路径地形最高 + 净空 + 100m」重跑（`terrain_alt_raised`，非区域级——避免把区域最大地形当目标值导致过度抬升破坏 restricted 底部/顶部剖面语义）；
- 抬升后仍无解 → 无过滤场保底（宁丑勿违）；抬升超升限不抬（保可用性）；
- 抬升生效时 warnings + degradations 显式提示 `"terrain clearance: cruise altitude raised X->Y (terrain up to Z)"`（`terrain_alt_raised`）。

### 步骤 5c — 禁飞墙膨胀 + 过渡带软罚（apply_inflation_and_band）

**5c 膨胀**：`inflation_cells = ceil(inflation_m / cell_m)`，多轮 8 邻域扩散（INF 墙向外扩张）；
**5c2 过渡带软罚**：BFS 距离变换（源 = INF 墙），墙外 2 格内代价渐变递增（`cost *= 1 + 0.5 × (1 − (d−1)/2)`，墙边 ×1.5 → 带外 ×1）。

> 参数经实验标定：band=2 / coef=0.5（双禁飞区窄缝 18.9km/7.8km 与真实场景均平滑；band=3 会把窄缝中间挤成锯齿，已弃）。目的：FMM 权衡代价后自然走离墙更远的栅格，拉直后 clearance 余量充足（防贴墙锯齿，主管 2026-08-05 双禁飞区场景实测）。

### 步骤 5b — 雷达静态代价（M3）

```
对每格点:
    p = threat.static_union_probability(lon, lat)
    if p > 0 && cost 有限:
        u = threat.static_penetration(lon, lat, 0.0)
        geom = (u < 1.0) ? (1.0 − u) : 0.0
        cost *= 1 + radar_cost_coef × (p + geom)
```

- `threat = SphericalRadarThreat::new(&radars, threat_params)`（base_p 已标定：Swerling1 下 R_eff 处 0.9，2026-08-13）；
- 无雷达 → 跳过。

### 步骤 6 — 每机：分段 FMM → 回溯 → 拼接 → 受限区剖面 → 平滑 → 输出

#### 6.1 段序列

`seg_ends = [start] + mid_waypoints + [target]`，逐段 FMM（共享代价场 field_ref）→ 回溯 → 去重拼接。

**P7 环带目标集（2026-08-12）**：末段（→ target）且有启用武器（`vehicle_weapon` 按 `<vehicle_id>_w1` 查 `mission.weapons`）时，回溯目标从单点改为**环带内 T 最小可达 cell**（`ring_target_cell` 全网格扫描距目标 ∈ [Rmin,Rmax] 的 cell，取 FMM 到达时间最小者 → `backtrack_path`）——等价"传播到环带即停"，路径停在**进入环带处（Rmax 外边界）**，不会继续深入 Rmin 内（带最小射程的武器不得停在 Rmin 内）。环带内无可达 cell → 点目标回退仅当目标点本身 ∈ 环带（Rmin≈0），否则 `no_solution` + degradation `"ring target unreachable"`。

#### 6.2 受限区剖面决策（restricted_detour_required / restricted_pass_alt）

**核心语义（主管 2026-08-06 二轮+三轮）**：飞行高度落在 restricted 高度区间内时：

- 决策 `restricted_pass_alt`（圆/多边形受限区同语义——2026-08-12 起多边形不再走水平绕行；d_in/d_out 按形状：圆=到圆心距离−半径，多边形=到边界最近距离，点在内=0；穿行带判据 `line_polygon_inside_bands` 直线段在多边形内部参数带，凹多边形多带）：
  - **底部穿行**：`bottom = alt_min − 500m`，需满足：`bottom ≥ 0`（负高不可行——0m 仍在 [0,alt_max] 区间内）∧ `bottom < alt_min`（穿行高度必须在区间外）∧ 爬升距离够（start/target 到圆边界 ≥ 1.25×|alt−pass|/tan(max_climb)）∧ **穿行带地形可行**（直线穿圆段地形 ≤ bottom − 100m 净空；**判据 = 直线穿行带而非整个圆面**——圆角落高山不参与判据，三轮纠偏；**采样与剖面几何对齐（2026-08-11 zigzag31）：raw_band 分支沿 raw 子段加密采样（间隔 ≤200m，同 verify 口径，clamp [8,2048]），平面分支步长 2.2km→200m——窄峰不漏检；fallback 分支 restricted_pass_alt 传段首尾 p0/p1（与剖面 in_out 段一致），不再传全局 start/target**）；
  - **顶部绕飞**：`top = alt_max + 500m`，需爬升距离够 ∧ `top ≤ ceiling_m`（升限）；
  - **决策**：底部可行恒选底部（垂直机动总量更小）；底部不可行 → 顶部；都不可行 → None（画墙水平绕行 fallback）；
- `restricted_detour_required`：区间内 ∧ pass_alt 为 None → 该机 FMM **画墙水平绕行**（两轮 FMM 机制，见 6.3）。

#### 6.3 两轮 FMM 尝试（fmm_attempt 0..2）

- 第一轮：只绕硬墙（NoFly/Obstacle），restricted 直穿；
- `build_restricted_profiles` 沿 raw 路径找穿行区间（进入点 in / 穿出点 out，段与圆相交判定）：
  - 切 5 段：`[首段@alt_m, desc→in 过渡直线(mask=true 跳过平滑, ≤15°), in→out raw 子段@pass_alt（绕行弧平飞）, out→climb 过渡直线(mask=true), 尾段@alt_m]`；
  - **desc/climb 锚点避开相邻 restricted 带（2026-08-10 zigzag22）**：锚点搜索拒绝位于**其他** restricted 圆带内的点（`in_other_band` 闭包）——否则 rz2 的 out_climb 完成点落在 rz1 圆内 → rz1 处理时 in_idx=0 → head 退化**单点带内段** → 平滑全败 → FINAL 带内直穿 1967 点网格楼梯（2129.9km）；
  - in→out 平飞段平滑前**硬墙外扩**（`push_out_of_walls`：距圆墙圆心 < radius+inflation+margin → 沿径向外移；margin=0.5km 吸收平滑内切与网格离散误差）；
  - **圆求交投影误差补偿**：等距投影把 1200km 长段当平面直线，而实际大圆路径向北极弯曲，投影与球面偏差 ~0.5–3km → 贴圆擦过（真实穿入 0.5km）会被算成不穿 → verify 放行非法路径。`segment_circle_intersect_t` 求交用 `r + slack`（`slack = max(1km, 段长×0.5%)`）扩大搜索区间，区间内采样点由 `zone_contains_at` **精确球面判定**——不误伤合法贴边；
  - raw 未穿圆（浅穿 < 格距）→ fallback：start→target **直线参数化剖面**（直线避开全部硬墙时可用；**P8 M6：直线穿硬墙 → 显式 degradation 标注 `restricted fallback straight profile blocked by wall (zone=…); raw shallow-cross delivered`，保持 raw 浅穿交付（零回归）——不触发画墙绕行：`need_wall` 全局画 restricted 墙会使 zz33/zz34（主管真实输入，rz 圆顶与 no_fly 三角顶点同高）走廊闭合 → no_solution，比锯齿交付更坏**）；
  - **剖面段穿硬墙检查**：desc_in/out_climb 过渡直线做 `line_hits_wall_km` 净距检查（剖面段可能斜穿 no_fly 多边形——zigzag12 教训），任一穿墙 → `need_wall = true` → **第二轮 FMM** 画 restricted 墙水平绕行兜底；
- 平滑段切分后，mask=true 的过渡段跳过平滑链（拉直会缩短水平距离 → 爬升角超 15°）；**段边界转角检查**（2026-08-08 zigzag19 + 2026-08-11 zigzag32/33 增强）：平滑循环每段 push 前检查边界转角 ≤ max_turn_deg，超限用 `arc_transition` 插过渡弧（后续段起点同步弧末点，防 65.9°>60° 转角触发全链回退 → 1975 点楼梯）。2026-08-11 起 `arc_transition` 带三件套防"插弧后段距墙不足"：① 插弧前逐段**净距预检**（`seg_zone_clearance_ok_arc`，`zone_segment_clearance_km` 与 verify 同口径：arc 各段 + 弧末点→出段第二点 ≥ inflation）；② 不足 → **弧末点外推到出段直线**（E' 距 b = 4×r，clamp 0.75×|bc|，段 E'→next 恢复 b→c 子段净距；弧内部转角 ≈3θ/4 < 60）；③ 外推前**细分弧重试**（min_steps 4..=8，净距+转角双检）；外推仍不足且转角 ≤65° → `turn_exempt` 兜底豁免（final 过滤为 warning，机动空间优先宁丑勿违）。

#### 6.4 平滑链 + 复验（2026-08-11 起在 fmm_attempt 解算循环内）

- `default_chain(&opts, &check)`：Theta\* → Catmull-Rom → Dubins → 贪心抽稀（固定翼；旋翼机无 Dubins）；
- `make_segment_check`：Theta\* 拉直判定（几何精确：Zone 净距 < inflation 拒绝；Restricted 高度采样；雷达深穿 < 0.7 拒绝拉直）；
- `VerifyContext`：terrain + nofly + zones + threat + zone_inflation_m；
- 每段独立平滑（mask=false 段），首尾段端点保留（必经点/目标硬约束）；
- **平滑链 + 全路径终检移入 `fmm_attempt` 解算循环**（2026-08-11 zigzag30：原 4 次 for → loop + attempts≤6 兜底）——`final_rep` 报地形净空不足 → 按 verify issue 地形高度**抬升重跑 FMM**（必须重跑：抬升可能改变 restricted 墙决策，不能只重跑平滑；抬升严格递增 `>alt_eff+0.5` 且 ≤ceiling，单调有界）——`SmoothResult.terrain_gap_m` 记录段级中间阶段复验地形净空不足的最大地形高度（verify ~200m 采样密于 check，窄峰不漏检），solver 抬升决策与 final_rep issues 解析取 max（并集）；
- 拼接后**全路径终检**（段间转角/整路径威胁在拼接后才可见）：
  - 通过 → 交付平滑路径；
  - 失败 → 回退未平滑拼接（`smoothing_failed` 告警 + degradations 记录）；**阶段1-D 硬闸（2026-08-11）**：随后尝试直线直穿替代 / 雷达直穿替代，均失败 → **`no_solution`，不交付 raw**（"宁可不给路径，也不给违禁路径"；失败原因保留 warnings + stderr JSON）。

#### 6.5 直线直穿替代（主管 2026-08-05 锯齿问题修复）

FMM 直穿雷达区时 Theta\* 拒绝拉直（check 穿雷达 = false）→ 交付网格锯齿。修复逻辑：

```
rep_now = threat.evaluate(当前路径)
if rep_now.over_threshold && 路径某点深穿任一雷达有效半径 70% 以内（penetrates）:
    构造分段直线（起点+必经点+目标，去重）
    if 当前距离 > 直线距离 × 1.05 + 1000m（锯齿是网格伪影而非真实绕行）:
        verify 直线（过几何复验：防穿山/超机动）
        if 通过 → 交付直线直穿；撤销 smoothing_failed 误报；
              degradations 记 "radar: unavoidable crossing -> straight-line transit (p ...)"
```

> 直穿判定与 P_cross 解耦（主管 2026-08-06）：P_cross 是验收阈值，不参与直穿判定——航路必须绕开雷达探测区域，不得因调高 P_cross 而直穿。

#### 6.6 输出

```rust
VehicleOutput { id, status: "planned", path: Vec<PathPoint>, distance_m, warnings }
```

- 粗层 FMM 无解 → `status: "no_solution"` + warning "coarse FMM no path"（`continue 'veh`，不中断其他机）；

## 4. 关键辅助函数

| 函数 | 说明 |
|------|------|
| `region_of` | 任务区域包围盒 + 0.15° 缓冲（源/目标不贴边）；**2026-08-11 起叠加障碍感知外扩**：硬墙（NoFly/Obstacle）bbox 超出任务区域时并入 region（多边形墙余量 0.15°、圆墙 0.03°），修复"墙占满 region 短边 → 绕行被迫出 region → coarse FMM no path 误报 no_solution"（zz36 回归）；grid 按外扩后 span 等比上调保持 cell（软罚带物理宽度不变） |
| `expand_region_for_walls` | 障碍感知外扩（见 `region_of` 说明；Restricted 不画墙不纳入；圆墙小余量避免撑出 region 触发 terrain 墙格点翻转——zz19 教训） |

## 5. 与设计的差异/占位

| 项 | 设计 | 当前实现 |
|----|------|---------|
| 无解出口链 ①②③④⑤ | 完整降级链 | ✅ 已实现（P8 2026-08-13 补全③④：③ 点目标回溯失败 → 目标半径放宽重试（`relaxed_target_cell`，10km 上限，T 最小可达 cell）+ degradation；④ 粗层 FMM no path → 网格细分重试（grid×2 上限 1024，`build_cost_field` 提取复用）+ degradation；细分后仍无解 → 几何无解分类；② 穿越评估 → 直线直穿替代 + 告警；① 压制重算；⑤ 明确报错） |
| 3s 预算硬护栏 | 端到端 ≤3s + 降级链 0.5s | P6-B 已实现：`SolveParams.time_budget_ms`（CLI 默认 3000，`ARP_BUDGET_MS=0` 关闭，测试/CI 确定性用）；超预算且有已完成车辆 → `degraded_timeout` + 部分结果（warm best-so-far）；无候选 → `DegradedTimeout` |
| warm best-so-far | 持续维护最优合法候选 | 部分实现（P6-B）：超时返回已完成车辆路径；单机/无候选场景不缓存中间候选（chain 式流程 verify 通过即成功，无多候选竞争） |
