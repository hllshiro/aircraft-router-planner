# 07 — 求解器与端到端流程

> 代码位置：`cli/src/solver.rs`（1884 行，含测试）
> 设计依据：技术方案 Phase 4 M1–M5（主管 2026-08-05 拍板拆分）、4.2.1（无解出口/默认参数表）、多轮主管现场决策（2026-08-05/06）

## 1. 职责

`solver::solve` 把 Phase 0-3 的库层组件串成主流程：

```
parse → validate（main）→ TerrainSource（ARPK1/无地形）→ 语义代价场
（Land/Water/NoData/NODATA 5x + Zone 硬墙 INF）→ FMM → 回溯 → 平滑链
（Theta* 去锯齿 + 抽稀 + Dubins 拟合 + 复验门）→ VehicleOutput 契约
```

**M1 范围（主管拍板 2026-08-05）**：单机/多机（共享代价场，每机独立 FMM）；Zone 水平几何禁入（高度层 M2）；SmoothOptions 默认值（VehicleProfile 派生 M4）；雷达代价（M3）；target_ref 暂按 mission.target（M5 每机 waypoints）。

## 3. solve() 主流程（分步）

### 步骤 1 — 地形源构建

- `terrain.source = none` → `None`（海拔 0 平面）；
- 否则：`--terrain` 参数 > `terrain.path` 字段；都缺省时**默认低精度地形 = 量化中国数据**（`china_dem_l12.arpack`）：
  - 候选路径：exe 同目录 → `china_dem_l12.arpack` → `phase0/data/pending/...` → `../phase0/data/pending/...` → exe 祖先目录（上溯 3 层）逐个试；
  - 全部不存在 → `AppError::Data`（terrain 声明但文件缺失）。

### 步骤 2 — 车辆规格

- `vehicles` 空 → 默认单机 `v1`（mission.start → mission.target，`VehicleProfile::default()` = 固定翼 + 全占位）；
- 否则每机解析：mid_waypoints 经纬度校验。

### 步骤 3 — 任务区域（Region）

- 所有起点 + target 的方形包围盒 + 0.15° 缓冲（保证源/目标不贴边）；
- `span_deg = max(经度跨度, 纬度跨度) + 2×0.15`（正方形）。

### 步骤 4 — Zone 集合与索引

- `all_zones = no_fly ∪ restricted ∪ obstacles`；
- `circle_index`：圆形 Zone → `CircleIndex`（平滑复验的快速路径）；
- **墙策略（M2 高度层）**：NoFly/Obstacle → 全高度水平墙（代价场 INF）；Restricted → 不画墙（区间外可穿越），由 Theta\* check + verify 高度判定。

### 步骤 4b — 参数合并 + 禁飞区膨胀距离

- `DefaultParams::default().merge(&input.mission.parameters)`；
- `radar_param_degradations`：无效输入参数回落默认的事实记入 degradations；
- **膨胀距离**（主管 2026-08-06：绕飞太贴边 → 考虑飞机机动）：`inflation_m = max(每机 phys×0.5, clamp[2km, 10km])`，其中 `phys = v²/(g·tanφ)` 物理转弯半径（`smooth_options_for` 派生）。

### 步骤 5 — 语义代价场

```rust
build_semantic_cost_field(grid, grid, |r, c| {
    (lon, lat) = cell_lonlat(r, c)
    若在任一硬墙 Zone 内 → Sample::OutOfBounds
    否则 terrain.sample_at(lon, lat)（无地形 → Land(0.0)）
}, 5.0)   // NoData 5x
```

- `cell_lonlat`：格点中心经纬度（`min + (i+0.5)/grid × span`）；
- `lonlat_cell`：经纬度 → 格坐标（clamp 到 [0, grid-1]）。

### 步骤 5c — 禁飞墙膨胀 + 过渡带软罚（apply_inflation_and_band）

**5c 膨胀**：`inflation_cells = ceil(inflation_m / cell_m)`，多轮 8 邻域扩散（INF 墙向外扩张）；
**5c2 过渡带软罚**：BFS 距离变换（源 = INF 墙），墙外 2 格内代价渐变递增（`cost *= 1 + 0.5 × (1 − (d−1)/2)`，墙边 ×1.5 → 带外 ×1）。

> 参数经实验标定：band=2 / coef=0.5（双禁飞区窄缝 18.9km/7.8km 与真实场景均平滑；band=3 会把窄缝中间挤成锯齿，已弃）。目的：FMM 权衡代价后自然走离墙更远的栅格，拉直后 clearance 余量充足（防贴墙锯齿，主管 2026-08-05 双禁飞区场景实测）。

### 步骤 5b — 雷达静态代价（M3）

```
对每格点:
    p = threat.static_union_probability(lon, lat)
    if p > 0 && cost 有限:
        u = threat.static_penetration(lon, lat, 0.0)
        geom = (u < 1.0) ? (1.0 − u) : 0.0
        cost *= 1 + radar_cost_coef × (p + geom)
```

- `threat = SphericalRadarThreat::new(&radars, threat_params)`（base_p 固定 0.1 占位）；
- 无雷达 → 跳过。

### 步骤 6 — 每机：分段 FMM → 回溯 → 拼接 → 受限区剖面 → 平滑 → 输出

#### 6.1 段序列

`seg_ends = [start] + mid_waypoints + [target]`，逐段 FMM（共享代价场 field_ref）→ 回溯 → 去重拼接。

#### 6.2 受限区剖面决策（restricted_detour_required / restricted_pass_alt）

**核心语义（主管 2026-08-06 二轮+三轮）**：飞行高度落在 restricted 高度区间内时：

- 决策 `restricted_pass_alt`（仅圆形受限区，多边形 → None 走水平绕行）：
  - **底部穿行**：`bottom = alt_min − 500m`，需满足：`bottom ≥ 0`（负高不可行——0m 仍在 [0,alt_max] 区间内）∧ `bottom < alt_min`（穿行高度必须在区间外）∧ 爬升距离够（start/target 到圆边界 ≥ 1.25×|alt−pass|/tan(max_climb)）∧ **穿行带地形可行**（直线穿圆段地形 ≤ bottom − 100m 净空；**判据 = 直线穿行带而非整个圆面**——圆角落高山不参与判据，三轮纠偏）；
  - **顶部绕飞**：`top = alt_max + 500m`，需爬升距离够 ∧ `top ≤ ceiling_m`（升限）；
  - **决策**：底部可行恒选底部（垂直机动总量更小）；底部不可行 → 顶部；都不可行 → None（画墙水平绕行 fallback）；
- `restricted_detour_required`：区间内 ∧ pass_alt 为 None → 该机 FMM **画墙水平绕行**（两轮 FMM 机制，见 6.3）。

#### 6.3 两轮 FMM 尝试（fmm_attempt 0..2）

- 第一轮：只绕硬墙（NoFly/Obstacle），restricted 直穿；
- `build_restricted_profiles` 沿 raw 路径找穿行区间（进入点 in / 穿出点 out，段与圆相交判定）：
  - 切 5 段：`[首段@alt_m, desc→in 过渡直线(mask=true 跳过平滑, ≤15°), in→out raw 子段@pass_alt（绕行弧平飞）, out→climb 过渡直线(mask=true), 尾段@alt_m]`；
  - in→out 平飞段平滑前**硬墙外扩**（`push_out_of_walls`：距圆墙圆心 < radius+inflation+margin → 沿径向外移；margin=0.5km 吸收平滑内切与网格离散误差）；
  - raw 未穿圆（浅穿 < 格距）→ fallback：start→target **直线参数化剖面**（直线避开全部硬墙时可用）；
  - 剖面段穿硬墙 → `need_wall = true` → **第二轮 FMM** 画 restricted 墙水平绕行兜底；
- 平滑段切分后，mask=true 的过渡段跳过平滑链（拉直会缩短水平距离 → 爬升角超 15°）。

#### 6.4 平滑链 + 复验

- `default_chain(&opts, &check)`：Theta\* → Catmull-Rom → Dubins → 贪心抽稀（固定翼；旋翼机无 Dubins）；
- `make_segment_check`：Theta\* 拉直判定（几何精确：Zone 净距 < inflation 拒绝；Restricted 高度采样；雷达深穿 < 0.7 拒绝拉直）；
- `VerifyContext`：terrain + nofly + zones + threat + zone_inflation_m；
- 每段独立平滑（mask=false 段），首尾段端点保留（必经点/目标硬约束）；
- 拼接后**全路径终检**（段间转角/整路径威胁在拼接后才可见）：
  - 通过 → 交付平滑路径；
  - 失败 → 回退未平滑拼接（`smoothing_failed` 告警 + degradations 记录，宁丑勿违）。

#### 6.5 直线直穿替代（主管 2026-08-05 锯齿问题修复）

FMM 直穿雷达区时 Theta\* 拒绝拉直（check 穿雷达 = false）→ 交付网格锯齿。修复逻辑：

```
rep_now = threat.evaluate(当前路径)
if rep_now.over_threshold && 路径某点深穿任一雷达有效半径 70% 以内（penetrates）:
    构造分段直线（起点+必经点+目标，去重）
    if 当前距离 > 直线距离 × 1.05 + 1000m（锯齿是网格伪影而非真实绕行）:
        verify 直线（过几何复验：防穿山/超机动）
        if 通过 → 交付直线直穿；撤销 smoothing_failed 误报；
              degradations 记 "radar: unavoidable crossing -> straight-line transit (p ...)"
```

> 直穿判定与 P_cross 解耦（主管 2026-08-06）：P_cross 是验收阈值，不参与直穿判定——航路必须绕开雷达探测区域，不得因调高 P_cross 而直穿。

#### 6.6 输出

```rust
VehicleOutput { id, status: "planned", path: Vec<PathPoint>, distance_m, warnings }
```

- 粗层 FMM 无解 → `status: "no_solution"` + warning "coarse FMM no path"（`continue 'veh`，不中断其他机）；
- `Stats { fmm_ms, los_checks: 0, degradations }`。

## 4. 关键辅助函数

| 函数 | 说明 |
|------|------|
| `region_of` | 任务区域包围盒 + 0.15° 缓冲 |
| `cell_lonlat` / `lonlat_cell` | 格坐标 ↔ 经纬度 |
| `circle_index` | 圆形 Zone → CircleIndex（polygon 过滤） |
| `radar_threat_params` | DefaultParams → ThreatParams（base_p 固定 0.1） |
| `radar_param_degradations` | 无效参数回落事实 → degradations |
| `join_paths` | 多段拼接（去重相邻重复点；段端点保留） |
| `make_segment_check` | Theta\* 段检查闭包（Zone 几何精确 + Restricted 高度采样 + 雷达深穿） |
| `restricted_blocks_alt` | 飞行高度是否落在 restricted 区间内 |
| `dist_km` | 度制近似平面距离（km，短距离 <100km 够用） |
| `restricted_pass_alt` | 受限区穿行高度决策（底部/顶部） |
| `bottom_terrain_ok` | 穿行带地形可行性（直线穿圆段采样，步长 ~2.2km，clamp [8,64] 点） |
| `restricted_detour_required` | 是否必须画墙水平绕行 |
| `line_hits_wall_km` | 直线段是否穿/贴任一硬墙（净距 ≤0 或 < inflation） |
| `build_restricted_profiles` | 受限区剖面切分（5 段 + fallback 直线剖面） |
| `push_out_of_walls` | 逐点外扩到硬墙安全距离外（in→out 平飞段用） |
| `apply_inflation_and_band` | 禁飞墙膨胀 + 过渡带软罚（BFS 距离变换） |

## 6. 测试覆盖（solver.rs 内）

- `m1_end_to_end_plain`：无地形直航端到端（路径 ≥2 点、距离 ≈150km、起终点容差 0.02°）；
- `m1_no_solution_when_target_blocked`：巨型禁飞区覆盖目标 → no_solution；
- `twin_zone_smooth_after_band_penalty`：双禁飞区并列（20km 圆 + 6 边形）→ 过渡带软罚后平滑（≤10 点、无 smoothing_failed）；
- `bottom_pass_band_ignores_corner_mountain`：圆角落 700m 山不参与底部判据（穿行带 50m → 底部 1500m 可行）；
- `restricted_pass_alt_top_flyover_vs_bottom_descent`：底部 vs 顶部决策、升限约束、区间外不拦截；
- `restricted_pass_alt_zero_alt_min_forces_top`：alt_min=0 → 底部负高不可行 → 顶部 5500m；
- `build_restricted_profiles_top_flyover_profile`：底部被地形挡 → 顶部绕飞剖面。
