# 09 — 演示应用（Demo）

> 定位：**开发期工具**——可视化参数输入 + 航路验证；核心发布物不含 Demo。

## 1. 总体结构

```
src/demo/
├── server/    # Rust + Axum 后端（单进程：API + 静态前端）
└── web/       # React 18 + TS + Vite + Three.js（pnpm）
```

`install/demo/` 独立打包：`demo-server.exe` + `web-dist/` + `start-demo.bat/.sh`——复制到任意机器双击即用。

## 2. 后端

### 2.1 POST /api/plan

- 接收完整 Input JSON → 管道写入 CLI 二进制 stdin → 读取 stdout → 透传 Output JSON
- CLI 二进制定位：`ARP_CLI` 环境变量优先 → exe 同目录 → 常见 workspace 相对路径

### 2.2 POST /api/terrain

- 请求：`{ path, bbox, grid }`
- 响应：`{ nx, ny, bbox, resolution, heights }`

### 2.3 GET /api/data-files

返回 `data/index.yaml` 内容，前端下拉选择候选项。

## 3. 前端

### 3.1 核心组件

- **ControlPanel**：参数编辑面板（飞行器、雷达、Zone、地形选择）
- **Scene3D**：Three.js 3D 场景（z=-北 右手系）
- **tiles.ts**：视口瓦片加载（LRU 缓存 + 并发 + 层级切换）

### 3.2 数据流

```
ControlPanel 状态 → api.ts 调用 → 结果渲染到 Scene3D
```

## 4. 底图三源

- **掩膜**：GSHHG 海陆掩膜
- **GeoTIFF**：高程数据
- **WMS 代理**：在线地图服务

## 5. 启动方式

```bash
# 开发模式（一键启动）
pnpm demo:start              # 同时启动后端 :3001 和前端 :5173

# 启动前先构建
pnpm demo:start:build

# 单独启动
pnpm demo:server             # 后端 :3001
pnpm demo:dev                # 前端 :5173

# 构建命令
pnpm cli:build               # 构建 CLI
pnpm demo:build              # 构建前端

# 完整发布
pnpm release
```

## 6. 环境变量

| 变量 | 说明 |
|------|------|
| `ARP_CLI` | CLI 二进制路径（覆盖自动检测） |
| `DEMO_WEB_DIR` | 前端静态文件目录（覆盖默认 web-dist/） |
| `DATA_DIR` | 数据目录（覆盖默认 data/） |
