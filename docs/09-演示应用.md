## 2. 后端（demo/server）

### 2.1 POST /api/plan

- 接收完整 Input JSON（v0.21 契约，不含 `schema_version`）→ `serde_json::to_string` → 管道写入 CLI 二进制 stdin → 读取 stdout → 透传 Output JSON；
- **转发前把 terrain.path 相对路径解析为绝对路径**（`resolve_terrain_path` 多候选，见 2.8）——开发模式 `data/xxx.arpack` 与独立包形态都能让 CLI 打开；
- CLI 二进制定位（`cli_bin`）：`ARP_CLI` 环境变量优先（存在才用，误设回退候选）→ exe 同目录 / 上级目录（含 `.exe` 后缀，独立包形态：`install/demo/demo-server.exe` → `install/aircraft-router-planner-cli.exe`）→ 常见 workspace 相对路径（`target/release/` 等）；
- CLI 非零退出 / 空输出 → 返回 `input_invalid` + `INTERNAL_SERVER_ERROR` 错误体（不崩溃）。

### 2.2 POST /api/terrain

- 请求：`{ path, bbox: [min_lon, min_lat, max_lon, max_lat], grid: [nx, ny]? }`；
- **bbox/grid 缺省支持（2026-08-11）**：`bbox=null` → 数据实际范围（`source_bounds`）；`grid=null` → 按跨度自适应（目标格距 0.008° ≈ 0.9km，上限 128→256）；前端显式发送 `bbox ?? null / grid ?? null`（省略字段会让旧 server 400——JSON.stringify 省略 undefined 字段 → 反序列化失败，2026-08-11 主管实测）；
- 通过 `open_source` 打开 ARPK1 文件（**进程内缓存**：OnceLock<Mutex<HashMap<path, Arc<TerrainSource>>>）；
- 响应：`{ nx, ny, bbox, resolution, source_bounds, heights: (number|null)[] }`；
- `height_at` 返回 NaN → null（serde_json 不支持 NaN 序列化）；
- bbox 非法（min ≥ max / 非有限）→ `{ error: "invalid bbox" }`。

### 2.3 POST /api/elevation（单点地面海拔，2026-08-14）

- 请求：`{ path, lon, lat }`；
- 响应：`{ elevation_m: number | null }`（MSL 米；范围外/无数据/失败 → null）；
- 复用核心 lib 地形源（`get_source` 缓存）；
- 用途：前端起终点高度输入框 `min` = 该点地面海拔（防抖查询；查询失败静默无 min）。

### 2.4 POST /api/basemap（底图三源，2026-08-13 主管定稿）

统一契约：**经纬度 bbox 对齐的 RGBA 网格**（nx×ny×4，上限 256×256），前端按 bbox 直接贴图（不感知投影差异）：

- 请求：`{ source: "mask" | "tiff" | "wms", path?, bbox: [min_lon, min_lat, max_lon, max_lat], grid: [nx, ny], tiffProjection? }`；
- `source="mask"`：GSHHG 海陆掩膜（0=海 / 1=陆 / 2=湖）→ 三色填充（海 `#1a3a5c` / 陆 `#8a9a6a` / 湖 `#3a6a8a`）；
- `source="tiff"`：GeoTIFF（支持 EPSG:4326 经线网格 / EPSG:3857 Web Mercator 重采样；LZW/Deflate/无压缩/JPEG 压缩均支持）；存在 `.ovr`（GDAL 外部金字塔）时优先读最合适分辨率层（大图快速加载），无合适层回退主文件；主文件"全量解码"像素上限 30M（≤ 此值全读 + 双线性），超过走**抽稀降级**（边解码边抽稀）；原始字节 >800MB 报错建议 `gdaladdo -ro`；
- `source="wms"`：视口级单图请求（见 2.5）；
- **TIFF 解码缓存**（2026-08-13 瓦片化后）：按路径缓存"抽稀/ovr 全图"（CachedTiff），首次解码后所有瓦片从缓存采样（~10ms/瓦片），grid 固定 128×128 → 抽稀全图恒定可复用；
- 掩膜路径复用 `resolve_terrain_path`（2.8）逻辑。

### 2.5 GET /api/wms（GeoServer 代理）

- 本地 GeoServer WMS 1.1.1 代理（固定 WMS 1.1.1 + SRS；规避 1.3.0 轴序陷阱——**默认 GeoServer 未开 CORS，WMS 必须经后端代理**）；
- 请求参数透传（layers / bbox / width / height / format 等）；`wmsSize`（前端）按视口跨度换算请求像素；
- 前端瓦片系统对 WMS 不按瓦片切——按相机视口 bbox 请求一张图，覆盖所有可见瓦片。

### 2.6 POST /api/tile（瓦片合并端点，2026-08-13）

- 一次请求返回**地形 + 底图**（同 bbox 同 grid 一次采样），rgba 用 **base64** 编码（JSON 体积减 ~60%），逼近网页地图加载体验；
- 瓦片化后每瓦片 1 请求替代 /api/terrain + /api/basemap 2 请求（单瓦片 ~30ms）；底图错误单独返回（`baseMapError`），不拖死地形（2026-08-14 修复：底图失败不残留 overlay/不阻塞 terrain）。

### 2.7 服务启动（单进程）

```rust
Router::new()
    .route("/api/plan", post(plan_route))
    .route("/api/terrain", post(terrain_route))
    .route("/api/elevation", post(elevation_route))     // 2026-08-14 单点海拔
    .route("/api/basemap", post(basemap::basemap_route)) // 2026-08-13 底图三源
    .route("/api/tile", post(tile_route))                // 2026-08-13 瓦片合并端点
    .route("/api/wms", get(basemap::wms_proxy))          // 2026-08-13 GeoServer 代理
    .fallback_service(ServeDir::new(web_dir).not_found_service(ServeFile::new(index)))
    .layer(tower_http::cors::CorsLayer::permissive());   // 开发期全放开 CORS
// 绑定 0.0.0.0:{DEMO_PORT|3001}
```

- 静态目录：环境变量 `DEMO_WEB_DIR` 覆盖，默认 exe 同目录 `web-dist/`（独立包形态 `install/demo/web-dist/`）；
- 端口：环境变量 `DEMO_PORT`，默认 3001。

### 2.8 可移植地形路径解析（resolve_terrain_path，2026-08-10）

前端默认地形为相对路径 `data/east_asia_7p5as.arpack`（开发模式 cwd=workspace 根命中）；独立包把地形放 `install/` 根（`east_asia_7p5as.arpack`），`demo-server.exe` 位于 `install/demo/`。依次尝试：

## 3. 前端（demo/web）

### 3.1 类型与坐标工具（types.ts）

- **契约类型**：完全对齐 `cli/src/config.rs`（InputConfig / AircraftInput / AircraftProfile / Radar / Zone / TerrainConfig / ParamsOverride / PlanResult / AircraftOutput / TerrainInfo）；
- **底图类型**（2026-08-13）：`BaseMapSource = 'mask' | 'tiff' | 'wms' | 'none'`（三选一 + none）、`TiffProjection = 'auto' | '4326' | '3857'`（auto = 后端读 GeoKey 自动识别）、`BaseMapConfig { source, path?, tiffProjection?, wmsUrl?, wmsLayers?, wmsCrs? }`；
- **坐标工具**：

```ts
geoToLocal(wp, ref, zScale): [x, y, z]     // 等距近似：x=(lon−refLon)×111320×cos(lat0)，y=(lat−refLat)×110574，z=alt×zScale

```

- **默认配置**（北京近郊演示场景）：默认飞行器 `a1`，start (115.9, 39.8) → target (116.8, 40.3)，固定翼 250 m/s / r=442m / 爬升角 15°，地形 `data/east_asia_7p5as.arpack`（537MB，GMTED2010 东亚 7.5as，70–135°E × 15–55°N，2026-08-10 与发布版 install/ 默认地形对齐）；起终点逐机结构化（`aircraft[0].start/target`，v0.21 起目标不再用魔法字符串）。

### 3.2 API 层（api.ts）

- `planRoute(config)` → POST /api/plan；
- `fetchTerrain(path, bbox, grid)` → POST /api/terrain（error 字段 → throw）；
- `fetchElevation(path, lon, lat)` → POST /api/elevation（单点地面海拔；失败静默返回 null，2026-08-14）；
- `fetchTile(...)` → POST /api/tile（地形+底图合并瓦片；2026-08-13）；
- `fetchWmsBlob(...)` / `wmsSize(...)` → GET /api/wms 视口级单图（2026-08-13）；
- 所有请求经 `readJsonResponse` 兜底：**空 body / 非 JSON / 非 2xx → 明确中文错误**（2026-08-13 修复，不再裸 `resp.json()` 抛 "Unexpected end of JSON input"）；
- `sceneBounds(config)`：`aircraft[].start/target` 包围（点击设置终点在场景外时 bbox 自动扩展），跨度 = max(实际距离 × 1.4, 最小 2.5° 经度 × 2.2° 纬度)（2026-08-06 起替代固定 ±600km；保证地形网格覆盖全场景 + 余量）。

### 3.3 App.tsx（主界面状态）

- 状态：`config` / `result` / `loading` / `clickMode`（'start' | 'target' | 'midpoint' | 'polygon' | null）/ `pickVehicleIdx`（每机拾取目标下标）/ `editingZoneId` / `terrainData` / `terrainError` + **底图状态**（`baseMapConfig` / `baseMapLoading` / `baseMapError`）；
- **地形/底图加载 = 视口瓦片系统**（2026-08-13 起替代整图 96×96 加载）：`useViewportTiles`（tiles.ts）按相机视口增量加载瓦片——相机 change 节流 400ms → viewportBBox（中心尺度法：跨度 clamp 300km→2e7m，与远角无关，倾斜/缩放不抖动）→ coverTiles 生成层级瓦片（0.05°~90° 12 级，TILE_SPANS 扩展支持全球）→ 每瓦片 1 请求 /api/tile（128×128 网格，terrain+baseMap 合并）→ LRU 缓存 48 片（只删视口外）+ 并发 4 + **层级切换冷却 1200ms**（缩放抖动场景 20→2 次请求）；旧层级瓦片兜底渲染、活跃层级覆盖，无空洞；
- `handlePlan`：调用 planRoute，网络错误 → 本地构造 `input_invalid/NETWORK_ERROR` 结果；
- 交互回调：
  - `handleGroundClick`：地面拾取——start/target → 该机 `start` / `target`（每机独立，2026-08-10 起；v0.21 结构化）；midpoint → 添加必经点（高度取该机起点高度，保持模式可连续添加）；polygon → 追加多边形顶点；起点/终点选定后自动退出拾取模式；
  - `handleMidpointMove`：拖动必经点 → 更新 `mid_waypoints[index]` 经纬（高度保留）；
  - `handleRadarMove`（拖动雷达）、`handleZoneMove`（拖动区域）。

### 3.4 Scene3D.tsx（3D 场景）

- `@react-three/fiber` Canvas + OrbitControls + Grid；
- **场景坐标（2026-08-14 镜像修复）**：`x=东、y=上、z=-北`（物理右手系）——朝北看时东在右、北在上（地图式方位）；全局北取反（9 文件：tiles/TerrainMesh/StartMarker/TargetZone/PathLine/RadarSphere/MidpointMarker/NFZPrism/Scene3D 统一 `z=-北`）；**默认相机 = 正南高空俯视** `[0, 60000, 80000]`（az=180，看向原点即朝北）；`onCreated` 相机 `lookAt(0,0,0)`（收敛首帧视口 bbox 落点，避免首屏海色瓦片）；
- 圆形 zone → 24 边局部平面多边形（`circleToLocalPolygon`）；多边形 → 顶点映射；
- `GroundClickPlane`：地面拾取（防抖：同一位置 400ms 内只生效一次；雷达拖动后 400ms 抑制误设）；
- 渲染：StartMarker / TargetZone（全局目标蓝色）+ 每机自定义目标（红色小标记）/ RadarSphere（探测球+地面盘）/ NFZPrism（禁飞区棱柱，高度带）/ PathLine（多机独立颜色）/ TerrainMesh（**瓦片化地形网格，真实海拔 + 底图纹理贴面**，见下）/ **MidpointMarker（必经点黄色可拖动小球，Alt+点击新增由地面拾取层处理）**；
- **底图贴地形**（2026-08-13，删除原 y=-1 独立底图平面）：TerrainMesh 每瓦片 128×128 顶点 + `texture`（mask/tiff RGBA）或 `wmsTexture`（视口级 WMS 图），按 bbox 对齐贴面；底图存在时贴在地形表面并作用地形起伏/夸张；无底图时保持绿棕白高度着色；

- 轨道：起点/终点/雷达/区域/必经点均可拖拽（点击模式联动；必经点拖动期间禁用 OrbitControls + 结束后 400ms 抑制地面拾取）；**NFZPrism 拖动 `by+dz→by-dz` 修复（2026-08-14：z=-北 后 dz 方向取反，禁飞/限飞实测 dLon/dLat 均跟鼠标）**；
- **相机自适应 `fitCameraToBounds`**（2026-08-11 起终点更改 → 场景应扩展；跨度变化 <20% 不动相机）：2026-08-13 修复——点击设置终点在场景外时不再自动旋转干扰：去掉 `ctrl.target.set(0,0,0)`（保留用户旋转中心/pan 位置，仅沿视线方向调整距离）+ fit 期间临时禁用阻尼动画（drei OrbitControls 默认 enableDamping=true，位置突变被平滑成"自动旋转"观感）。

## 4. 启动方式

### 独立包（install/demo/，推荐给别人/其他机器）

## 6. 与发布的边界

- 核心发布物（单二进制 + 默认地形/掩膜）**不含 Demo**（主管裁决）；`install/` 完整安装包（CLI + data/ + demo/）为可选分发形态，Demo 在其中独立可运行、可删；
- CLI 二进制可被 `ARP_CLI` 环境变量指向任意构建产物（如交叉编译结果）；`DEMO_WEB_DIR` / `DEMO_PORT` 覆盖静态目录与端口；
- Web 禁飞区支持圆形（参数编辑）与多边形（顶点表格编辑 + 场景拾取顶点）两种形状；底图三源（掩膜/GeoTIFF/WMS）为单选，前端不在画布内悬浮独立底图平面——底图贴在地形表面。
