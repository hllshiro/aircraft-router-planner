## 二、模块级差异明细

### 2.1 坐标系统（coord.rs）

**设计状态**（技术方案.md §4.2.3）：
- 坐标系为任务级配置，输入 JSON `crs` 字段声明
- 默认输入坐标系 WGS 84
- `crs.datum` 可选 WGS84/CGCS2000/GRS80
- `input_projection` 支持 lonlat/utm/gk3
- `output_crs.projection` 支持 lonlat/utm/gk3/custom_tm

**代码实现**：
- 坐标系统已实现（446行）
- 椭球表、TM正反算、UTM/GK3/WebMercator、ENU、垂直基准均已实现
- WKT2 参数核对已写入编译期常量

**差异说明**：
- v0.21 起 `crs`/`output_crs` 移出输入契约
- 坐标系配置设计保留为后续版本规划线索
- 当前默认始终 WGS84 经纬度 + MSL

**更新后文档**：docs/07-坐标与投影.md

### 2.2 地形数据源（terrain/）

**设计状态**（技术方案.md §4.2.5）：
- TerrainSource trait 统一查询接口
- 五种数据源：SRTM/HGT、GeoTIFF、DTED/DTED2、ARPK1、内存网格
- ARPK1 自建紧凑格式（16-bit + 分块差分 + Zstd）
- GSHHG 海陆掩膜
- 数据存放：`data/` 目录

**代码实现**：
- TerrainSource trait 已实现（mod.rs 518行）
- 五种数据源均已实现
- ARPK1 语义位图 S5 于 2026-08-13 关闭（arpack+mask 两文件定案 + MaskedSource 覆盖）
- GSHHG 掩膜已实现（mask.rs 538行）
- 数据存放：`data/` 目录（gitignore）

**差异说明**：
- ARPK1 语义位图设计为可选，但实际定案为两文件方案
- 数据存放路径从设计时的 `data/terrain.zstd` 变为 `data/east_asia_7p5as.arpack`
- 文件命名按扩展名识别，不再依赖文件名前缀
- **terrain 索引 id 重构**（2026-09-16 Task 3）：输入 JSON 的 terrain 配置从文件路径（`source/path/mask_path`）改为索引 id（`arpack/mask`），对应 `data/index.yaml` 索引文件；help 输出动态展示可用地形候选项

**待办事项**：
- [ ] **CLI自动加载低精度掩膜、地形数据**：考虑如何实现CLI自动加载`data/`目录下的低精度掩膜和地形数据（主要是文件体积问题，需要设计合适的文件组织和发现机制）

**更新后文档**：docs/08-地形数据源.md

### 2.3 代价场与FMM（costfield.rs）

**设计状态**（技术方案.md §4.2.1）：
- 代价场由四类输入合成：地形、雷达威胁、禁飞/限飞区、蓝方武器压制
- 融合规则在 Phase 0 数据契约中固定
- FMM 传播：粗网格 1-2km，Godunov 迎风差分 + BinaryHeap 窄带
- 确定性堆实现

**代码实现**：
- CostField 数据结构已实现（524行）
- 语义代价场构建已实现
- FMM 传播已实现（Godunov 迎风差分 + BinaryHeap 窄带）
- 确定性堆实现（BTreeMap/fixed-order reduction）

**差异说明**：
- 设计中提到的"LOS mask 乘子"有意不进静态代价场
- 雷达代价实现为乘性放大，与设计一致
- 禁飞墙膨胀已实现（物理转弯半径 0.5×，clamp [2km,10km]）

**更新后文档**：docs/02-代价场与FMM.md

### 2.4 威胁模型（threat.rs）

**设计状态**（技术方案.md §4.2.1/4.3）：
- 默认球形模型（保守探测范围上界）
- 探测概率为必选接口（十轮主管裁决）
- 多雷达重叠区：概率并集 `1−∏(1−pᵢ)`
- LOS 地形遮蔽：有地形文件时启用
- 压制修正因子：仅输入显式声明时启用

**代码实现**：
- ThreatModel trait 已实现（391行）
- 球形雷达模型已实现
- 探测概率衰减（Swerling1/Linear/Exponential）已实现
- LOS 遮挡已实现
- 多雷达概率并集已实现
- 压制修正已实现

**差异说明**：
- LOS mask 有意不进静态代价场（solver.rs:507 设计注释）
- LOS 动态遮挡由 verify 威胁评估精确判定（真实地形 + 逐点采样）
- base_p 已标定（2026-08-13 方案 A：Swerling I 典型监视雷达模型，R_eff 处 base_p=0.9）

**更新后文档**：docs/03-威胁模型.md

### 2.5 求解器（solver.rs）

**设计状态**（技术方案.md §4.2.1）：
- 无解出口链：①压制 → ②探测概率穿越评估 → ③放宽目标范围 → ④走廊细分/重路由 → ⑤明确报错
- status 四态：success / degraded_timeout / no_solution / input_invalid
- 多机支持：一次 FMM 传播 + 多目标回溯
- 3s 预算硬护栏

**代码实现**：
- solve() 九步流程已实现（7149行）
- 无解出口链已实现
- status 四态已实现
- 多机支持已实现（共享 field，每机独立 FMM）
- 3s 预算硬护栏已实现（P6-B）

**差异说明**：
- 出口②（探测概率穿越评估）已简化为直线直穿替代 + 告警
- 出口③（放宽目标半径）已实现（10km 上限）
- 出口④（网格细分重试）已实现（grid×2 上限 1024）
- 多机交叉检测已实现（P6-C）
- 武器类型+射程语义已定案（P6-D）

**更新后文档**：docs/04-求解器与端到端流程.md

### 2.6 路径平滑（smooth.rs）

**设计状态**（技术方案.md Phase 3）：
- 策略链：Theta* 去锯齿 → Dubins/样条拟合 → 贪心抽稀 → 弦高复验
- 优先级：安全 > 运动学约束 > 美化
- 回退语义：复验失败回退上一策略环节
- 全链复验清单：弦高 + 转弯半径/转弯角 + 地形净空 + A6 物理自洽

**代码实现**：
- 平滑策略链已实现（1934行）
- Theta* 去锯齿已实现
- Chaikin/Catmull-Rom 样条已实现
- Dubins CSC + CCC 已实现（506行）
- 贪心抽稀已实现
- 全链复验已实现

**差异说明**：
- 3D Dubins 降级为 2D Dubins + 高程剖面独立插值（方案风险表已接受此降级）
- Dubins CCC（RLR/LRL 三圆弧 + 同点不同向单圆弧）已于 2026-08-13 P9 T2 实现
- 机型分流参数派生已实现（smooth_options_for）

**更新后文档**：docs/05-路径平滑与复验.md
