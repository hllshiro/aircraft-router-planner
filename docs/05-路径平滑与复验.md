# 08 — 路径平滑与全链复验

> 代码位置：`cli/src/smooth.rs`（1934 行）、`cli/src/path.rs`（190 行）、`cli/src/dubins.rs`（506 行）
> 设计依据：技术方案 Phase 3（输出美化链 + 九轮链序修正 + 十轮复验清单 + 十一轮回退语义）、Phase 4 M4（机型分流参数派生）

## 1. 设计定位

Phase 3 输出美化链——**纯几何后处理**：输入折线路径（经纬度+高度），输出平滑路径。

**默认链序（九轮共识）**：Theta\* 去锯齿 → Dubins/样条拟合 → 贪心抽稀 → 弦高/运动学复验。

**优先级（九轮共识）**：安全（不撞山/不越禁飞）> 运动学约束（机动可飞）> 美化（平滑/抽稀）。

**回退语义（十一轮共识 + 2026-08-11 阶段1-D 修订）**：任一复验失败回退上一策略环节；全链失败 → 链级交付**美化前原始折线** + 显式告警 `smoothing_failed`（链级契约保留，供 solver 兜底尝试）；**solver 出口（阶段1-D 硬闸）**：raw 回退后若直线替代/雷达直穿替代均失败（`smoothing_failed` 未被撤销）→ **明确输出 `no_solution`，不交付 raw**（主管 2026-08-11 拍板：不需要输出无法实现的路径；"宁可不给路径，也不给违禁路径"），失败原因保留在 warnings + stderr JSON 诊断。

## 4. 基础平滑算法

### 4.1 Theta\* 去锯齿（theta_star_smooth）

LOS 捷径简化——贪心跳点：

```
锚点 i 起，从路径末尾向前找第一个 check 通过的跳跃点 j（i,j 间直连合法）
保 i、j，删中间点；max_turn_deg 约束相邻航段转角（防弧线拉直成 61°+ 折线）
跳点转角超限（j 处转角 > max_turn_deg）→ 以 j 为终点插过渡弧（arc_transition，r_eff≥442，zz33）
跳点 check 起点用 out 实际末点（out.last()）——插弧后为弧点 E（≠ raw path[i]），
  漏检 E→path[j] 穿 restricted 圆 → 全链回退（zz34 教训）
复杂度 O(n²)（点列短，粗层走廊点数百级可接受）
```

### 4.2 Chaikin 角切割（chaikin_smooth）

每段取 1/4、3/4 插值点，保持端点；1-2 轮即够（过多收敛到线段本身）。

### 4.3 Catmull-Rom 样条（catmull_rom_spline）

每段插 samples_per_seg 点，首末段端点复制（自然边界）。**对"绕行弧线"输出曲率 ≈ 绕行半径的平滑样条，复验自然通过；对"锯齿直穿"样条曲率小 → 半径复验失败 → 回退 Dubins/直线替代（正确语义）**。

### 4.4 贪心双指针抽稀（greedy_simplify）

锚点 i，指针 j 从末尾向前找最大跳跃——(i,j) 内全部点相对线段 [i,j] 的弦高 ≤ 容差则保 j 删中间，否则 j 前移。保留首末点。O(n²)。

### 4.5 局部等距投影（LocalProjection）

以中点为中心：`to_xy: ((lon−clon)×k×111320, (lat−clat)×111320)`，`k = cos(clat).max(1e-6)`。用于平面计算（Dubins 拟合/航向/外接圆）。

## 5. Dubins 路径基元（dubins.rs）

**CSC 四类型（LSL / RSR / LSR / RSL）最短路径解析求解**：

- 坐标系 y 向上、航向角逆时针；L 圆心 = p + R·(−sinθ, cosθ)，R 圆心 = p + R·(sinθ, −cosθ)；
- 同向圆（L-L/R-R）用外切线（要求 d ≥ 2R）；异向圆（L-R/R-L）用内切线（d ≥ 2R）；
- 每种类型两个候选切线侧，取总长最小；
- 弧角按转向类型计算（L 逆时针 / R 顺时针）；
- **CCC（RLR/LRL）三圆弧已实现（2026-08-13 P9 T2）**——CSC 四类型全失败（d < 2R 退化）时兜底：t1 → t2(反向) → t3(=t1)，相邻圆反向 → 外切 → 圆心距 2R，c2 为圆(c1,2R) ∩ 圆(c3,2R) 交点（存在条件 d ≤ 4R），两交点各算总长取最小，构造保证切点航向连续；同点不同向（d→0）走单圆弧最小转角。DubinsPath 增 `ccc: Option<Ccc>` 扩展（sample/len 支持三段圆弧；CSC 路径 ccc=None 行为不变）。成功率测量点预期 ~100%（原 95% 失败 100% 归因 d<2R）。

```rust
pub struct DubinsPath { t1, t2, a1, straight, a2, c1, c2, n1, r }
pub fn dubins_path(p0, th0, p1, th1, r) -> Option<DubinsPath>  // 无解 → None，不 panic
pub fn dubins_shortest_len(...) -> Option<f64>
pub fn dubins_success_rate(samples, r) -> (ok, total, avg_len)
```

**防御**：r ≤ 0 / 非有限输入 → None；同点同向 → 零长度路径；切点航向连续性校验（1e-6 容差）。

### 5.1 Dubins 拟合（dubins_fit，smooth.rs）

- 首末 pose：显式 heading 或首末段航向（真北 → 平面角：`hd·rad − π/2`）；
- 平面 = LocalProjection（首末中点）；高度沿原折线插值（`height_on_polyline`——**高程剖面独立插值**，爬升角由复验检查）；
- 无解 → None（回退链继续）。

## 6. 全链复验器（verify_path）—— 十轮复验清单

```rust
pub struct VerifyContext<'a> {
    pub terrain: Option<&'a dyn TerrainSource>,
    pub nofly: Option<&'a CircleIndex>,          // 旧快速路径（仅水平圆）
    pub zones: Option<&'a [Zone]>,               // M2 完整语义（提供时优先于 nofly）
    pub threat: Option<&'a dyn ThreatModel>,     // 雷达软告警
    pub zone_inflation_m: f64,                   // 硬墙水平膨胀距离（0 = 不膨胀）
}
```

**复验清单**：

| 检查项 | 规则 | 机型 |
|--------|------|------|
| 航向连续性 + 转角 | 相邻段航向差 ≤ max_turn_deg | 仅固定翼 |
| 转弯半径 | 三点外接圆半径 ≥ turn_radius_m × 0.99（**局部投影测量**——半径是局部几何量，2026-08-10 zigzag28 起以三点局部投影计算，替代全局等距平面投影） | 仅固定翼 |
| 爬升角 | 段高度差/水平距离 ≤ tan(max_climb_deg) | 仅固定翼 |
| 地形净空 | Land: alt ≥ h + clearance；Water/Lake: alt ≥ clearance；NoData/OOB: **降级警告不阻断**（2026-08-11 放开输入点限制，旧"保守不通过"废弃）；Forbidden: 不通过 | 两机型 |
| 禁飞/限飞包含（A4/A5） | 硬墙：段净距 < inflation 拒绝（几何精确）；Restricted：解析二次方程求段-圆相交区间 [t1,t2]，区间内 5 点采样高度判定（浅穿不漏检） | 两机型 |
| 弦高（几何） | 相对美化前参考路径逐点最小距离 ≤ chord_tol_m | 两机型 |
| A6 物理自洽 | turn_radius ≥ phys_min_radius_m（参数化，Phase 4 接入） | 仅固定翼 |
| 雷达威胁（软） | cumulative_p > P_cross → warning（不阻断平滑，degradation 记录） | 两机型 |

> **Restricted 几何精确判定**（2026-08-06 new_rz 教训）：等距采样会漏掉浅穿/短弦（段贴圆擦过时采样点可能全在圆外），改为解析二次方程求相交区间再采样高度，浅穿 0.5km、弦 8.9km 也能检出。
> **投影误差补偿**（2026-08-08 zigzag22）：等距投影把长段当平面直线，而实际大圆路径向极地弯曲——1200km 长段投影与球面偏差 ~0.5–3km，贴圆擦过（真实穿入 0.5km）会被算成不穿。`segment_circle_intersect_t` 求交用 `r + slack`（`slack = max(1km, 段长×0.5%)`）扩大搜索区间，相交区间内采样点由 `zone_contains_at` **精确球面判定**（不误伤合法贴边）。check 与 verify 共用该函数，防"check 放行 verify 拒"链全回退 → 1967 点楼梯。

**采样密度**：每段等距 `verify_seg_samples`（默认 8）点（段内最坏情况：端点+中点+加密）；**地形采样间隔 1km→200m**（2026-08-11 zigzag29：1km 采样网格整体移相会漏 <1km 窄峰（terrain 2082m），200m < 7.5as 格距 230m，任意相位下 ≥1 采样点必落入 ≤230m 宽山峰格）。**阶段1-A 抽原语**：采样点数与单点判定由 `terrain_sample_count(seg_len, min_samples, max_samples)` / `terrain_point_clearance(terrain, lon, lat, alt, clearance)` 统一（verify 与 Theta\* check 共用，杜绝两处口径漂移）——verify 传 `max_samples = usize::MAX`（全采样，860km 长段 ~4300 点，zz30 教训：上限 1024 会漏 2480m 窄峰 → 穿山路径通过复验）；check 传 `max_samples = 1024`（O(n²) 贪心跳点每个候选段都查地形，性能关键）。

**机型分支（九轮共识）**：旋翼机跳过固定翼运动学硬拦（悬停原地转向/垂直机动在位置空间表现为急转/陡爬升，是**合法航路**，不得误判）；净空/禁飞/弦高对两机型一律硬约束。

## 7. 平滑器策略链（Smoother trait + 回退语义）

```rust
pub trait Smoother { fn name(&self) -> &str; fn smooth(&self, path: &Path) -> Option<Path>; }
```

策略实现：`ThetaStarSmoother` / `DubinsSmoother` / `CatmullRomSmoother` / `GreedySimplifySmoother`。

**默认链（default_chain）**：
- 固定翼：Theta\* 去锯齿（max_turn 约束）→ Catmull-Rom（16 点/段）→ Dubins 拟合 → 贪心抽稀；
- 旋翼机：Theta\* → 贪心抽稀（**不含 Dubins 全局拟合**——圆弧拟合会拉直/破坏悬停转向点；尖角由机型感知复验放行）。

**执行与回退（smooth_path_chain）**：

```
执行链记录每阶段 (name, path)
从链末向前回退：第一个 verify 通过的阶段即交付
  - dubins 阶段：弦高放宽到 DUBINS_CHORD_TOL_M = 1000m（绕行 L 形圆角 ~0.7km，
    100m 逼近容差会误杀合法绕行）；运动学/地形/禁飞仍严格复验
全部失败 → 链级交付 input 原始折线 + warning: "smoothing_failed: no smoothed stage
            passed full verification" + 失败诊断 JSON（阶段1-C：各阶段 issue/warning
            汇总输出到 stderr，事件名 smooth_chain_failed）
```

**solver 出口（阶段1-D 回退过硬闸，2026-08-11）**：链级回退到 raw 后，solver 依次尝试
直线替代（start→target 直连过 verify）与雷达直穿替代；**两者都失败 → 不交付 raw，
输出 `status: "no_solution"`**（`warnings` 保留 `smoothing_failed` 原因 + "raw fallback
withheld (hard-gate)"）。attempts>6 耗尽时输出 `fmm_attempts_exhausted` 诊断 JSON
（最近 3 次 final verify 失败原因）。

## 7.5 垂直剖面后处理（solver.rs，2026-08-14）

平滑链输出后，`solver.rs` 对全路径高度做最终垂直剖面加工（详见 07 文档 6.6）：

```
apply_vertical_profile(pts, start_alt_norm, target_alt_norm, alt_eff, mid_anchors)
  → terrain_follow_insert（250m 峰顶捕获；起终点段 15° 爬升/下降线插点）
  → apply_climb_rate（双向 ≤15°：前向限上升率、后向限下降率，不低于地形保底）
```

- **起终点贴地**：`start_alt_norm` / `target_alt_norm` = 用户设定高度（低于地面 MSL → 抬到地面），**不因中间地形被抬升**（中间段由方案 B 自动锚点爬升）；
- **terrain_follow_insert**：段内 250m 加密采样找最差峰插点；起终点段（1km 内 = 起飞/降落段）插入高度 = min(地形+净空, 端点+tan(15°)×距离) 且不低于地形——净空 <100 允许但不穿地；中间段按 地形+净空 保底（≥100m）；
- **apply_climb_rate**：双向坡度 ≤ max_climb_angle（15°），压低超陡爬升/下降段，不低于地形保底（净空优先，宁陡勿穿山）；
- 受限区底部穿行/顶部绕飞剖面段保持语义，不参与插值。
