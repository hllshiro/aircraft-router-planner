## 关键信息速查

- **status 四态**：`success` / `degraded_timeout` / `no_solution` / `input_invalid`
- **性能指标**：每百公里 ≤ 3s（端到端典型值），绝对不能崩溃（B9）
- **核心链路**：语义代价场 → FMM → 回溯 → Theta\* → 样条/Dubins → 抽稀 → 全链复验
- **确定性**：固定种子逐位可复现，构建期禁 FMA + 固定 target-cpu
