# 02 — 输入输出契约与数据校验

> 代码位置：`cli/src/config.rs`（1500 行）、`cli/src/error.rs`（123 行）、`cli/src/main.rs`（241 行）
> 设计依据：技术方案 4.2.1（默认参数表/无解出口/status 契约）、4.5（输入-约束-校验传导矩阵）、十三轮共识（多机契约/InputValidator/压制后距离输入化）

## 1. 总览

CLI 采用 **stdin/stdout JSON 管道**形态：stdin 读任务 JSON → stdout 输出结果 JSON。可选参数 `--input / --output / --seed / --config / --terrain / --grid`。所有字段 `deny_unknown_fields`（未知字段 = 畸形）。

```
main.rs 流程：
  read_input → Input::from_json_str（畸形 → input_invalid: malformed_json）
  → config::validate（InputValidator：退化输入 → input_invalid + 原因码）
  → solver::solve（成功 → Output::success；解算层错误 → input_invalid）
```

**status 四态契约**（输出 JSON 顶层）：

| status | 含义 | 触发 |
|--------|------|------|
| `success` | 规划成功（含每车 `planned` / `no_solution` / `degraded`） | 正常完成 |
| `degraded_timeout` | 超时返回可用结果（warm best-so-far） | 预算耗尽（当前 solver 未显式触发，机制就绪） |
| `no_solution` | 确定性无解 + 原因码 | 全出口链耗尽 |
| `input_invalid` | 非法/退化输入 + 原因码（**不进入算法**） | 解析/校验层拦截 |

> 关键语义：`no_solution` 不是失败，是确定性结论；非零退出（exit 2）只留给硬故障（IO/内部错误）；超时/无解不触发非零退出。

### 2.5 Zone（禁飞/限飞/障碍物）

```rust
pub struct Zone {
    pub id: String,
    pub zone_type: ZoneType,        // no_fly / restricted / obstacle
    pub shape: ZoneShape,           // circle{center,radius_km} / polygon{vertices}
    pub alt_min_m: Option<f64>,     // 高度区间下界（MSL）；仅 Restricted 使用，
                                    // NoFly/Obstacle 全高度禁入可省略（2026-08-12）
    pub alt_max_m: Option<f64>,     // 高度区间上界；同上（仅 Restricted 使用）
    pub height_semantics: HeightSemantics, // msl（默认）/ agl（仅 Restricted 有意义）
}
```

- `Zone::is_wall()`：NoFly/Obstacle 为**全高度水平墙**（FMM 代价场 INF）；Restricted 为高度层禁入（区间外可穿越，不画墙）。
- **禁飞区无高度范围**（2026-08-12 主管定案）：NoFly/Obstacle 全高度禁入，`alt_min_m`/`alt_max_m` 可省略（省略 = 全高度）；**Restricted 必须提供** `[alt_min, alt_max]`（`alt_min < alt_max`，validator 强制，缺失/倒置 → `out_of_bounds`）。
- AGL 语义：解析层结合地形高程换算 MSL（`zone_contains_at` 实现；ground 未知 → 保守视为在区间内，安全优先）。

### 2.7 WeaponEntry（武器条目，2026-08-12 主管定案：类型 + 射程，默认不启用）

```rust
pub struct WeaponEntry {
    pub weapon_id: String,
    pub weapon_type: Option<WeaponType>, // aam / agm / bomb；缺省 = 该武器默认不启用
    pub range_km: Option<[f64; 2]>,      // 射程 [Rmin, Rmax] km；缺省 = 按类型默认值
    pub fuze_type: String,               // （保留兼容，仅解析）引信类型
    pub envelope: Option<LaunchEnvelope>,// 发射包线（P7 2026-08-12 起消费：heading/alt 硬校验、speed 软校验；heading 下放平滑级）
    pub target_ref: Option<String>,      // （保留兼容，仅解析）打击目标引用
}

pub enum WeaponType { Aam, Agm, Bomb }   // 空空导弹 / 空地导弹 / 航空炸弹
```

- **武器语义 = 武器类型 + 武器射程**（主管 2026-08-12）：`weapon_type` 三选一（`aam` 空空导弹 / `agm` 空地导弹 / `bomb` 航空炸弹）。
- **武器类型默认不启用**：`weapon_type` 缺省 → 该武器不启用（`effective_range_km() = None`，即使提供了 `range_km`；规划按无武器 → 点目标语义处理）。
- **射程按类型默认**：`range_km` 缺省时按类型取默认值；显式提供优先。
- `effective_range_km()`：`weapon_type` 缺省 → `None`；启用时 = 显式 `range_km` 或类型默认。
- 校验：显式 `range_km` 必须有限且 `lo < hi`（倒置/非有限 → `out_of_bounds`）；类型/射程都缺省不报错（不启用）。
- **车辆关联**（P7 2026-08-12）：按 demo 契约 `weapon_id = "<vehicle_id>_w1"` 查 `mission.weapons` 关联到该车（隐式单机 v1 → `v1_w1`）；启用武器 → 该车目标语义切换为**环带目标集**（FMM 传播到距目标 ∈ [Rmin,Rmax] 环带即停，路径停在进入环带处/Rmax 外边界，不得停在 Rmin 内）；无武器 → 点目标语义（不回归）。

**LaunchEnvelope**：`heading_deg: Option<[f64; 2]>` / `alt_m: Option<[f64; 2]>` / `speed_mps: Option<[f64; 2]>`。

- **发射包线消费语义**（P7 2026-08-12，docs/技术方案 §4.2"冲突时以发射包线优先"）：
  - `heading_deg`：窗口 = 从 lo 顺时针扫到 hi（跨 0° 如 [350,10] = 20° 宽）；终端 heading 下放平滑级（末段 Dubins 终端 pose = 窗口中心）；交付前终检末段航向 ∈ 窗口，不满足 → `no_solution`（`geometrically_impossible` + degradation "launch envelope not satisfied"）。
  - `alt_m`：终点目标高度 clamp 到窗口（垂直剖面终点优先包线）；终检终点高度 ∈ 窗口，不满足 → `no_solution`。
  - `speed_mps`：巡航速度（`cruise_speed_mps` 或 `speed_range_mps[0]`）∈ 窗口；不满足 → 软校验（degradation 告警，规划不可调速度，不阻断交付）。

**默认武器映射表（2026-08-12 定案：类型 + 按类型默认射程）**：

| weapon_id | weapon_type | range_km（默认） | fuze_type |
|-----------|-------------|------------------|-----------|
| aam_medium | aam | [5, 40] | proximity |
| asm_air_ground | agm | [3, 120] | impact |
| jdam | bomb | [1, 15] | impact |

表外武器走兜底（`default_weapon_radius_km` = 10km）+ 告警。

## 3. 输出契约（Output）

```rust
pub struct Output {
    pub schema_version: String,        // "0.20"
    pub status: String,                // success / degraded_timeout / no_solution / input_invalid
    pub error: Option<ErrorBody>,      // status != success 时携带
    pub elapsed_ms: Option<u64>,
    pub vehicles: Vec<VehicleOutput>,  // 每机结果
    pub stats: Stats,                  // 统计
}

pub struct VehicleOutput {
    pub id: String,
    pub status: String,                // planned / no_solution / degraded
    pub path: Vec<PathPoint>,          // 航路点（x=经度, y=纬度, alt_m=MSL 米）
    pub distance_m: f64,
    pub warnings: Vec<String>,         // 复验警告（smoothing_failed / radar: ...）
}

pub struct Stats {
    pub fmm_ms: f64,                   // FMM 传播累计耗时
    pub los_checks: u64,               // LOS 检查次数（当前 0，静态代价场未计数）
    pub degradations: Vec<String>,     // 降级/回落记录（供下游签收）
}
```

**坐标口径（主管决策 2026-08-05）**：输入输出坐标点均为经纬高定义，`x = 经度（度，WGS84）`、`y = 纬度（度）`、`alt_m = MSL 几何高度（米）`。

> **垂直剖面语义（2026-08-12 主管 demo 轨迹倾斜修复；2026-08-13 P8 M2 多锚点扩展；2026-08-14 三反起终点贴地修订）**：输出 `PathPoint.alt_m` 不再恒等于巡航高度——起终点高度不同（`start_pose.alt_m` ≠ 目标高度）时，路径高度按累计水平距离从起点高度线性过渡到目标高度（轨迹呈现爬升/下降）；**必经点 `mid_waypoints[].alt_m` 为分段锚点**（P8 M2：起→必经点→终点按段内比例插值；缺省同起点高度 = 无效果，行为同单段线性过渡）。规则：
> - **起终点贴地（2026-08-14 三反）**：起终点高度 = 用户设定硬约束（起飞/降落场景贴地合理，不加净空）；仅当低于当地地面 MSL 时物理保底抬升到地面（warnings `"start/target altitude below terrain: raised ..."`）；**不因中间地形被抬升**——中间段由方案 B 自动锚点爬升（撞山区段最高地形点 → 自动中间锚点 `(lon, lat, 抬升高度)`，`apply_vertical_profile` 据此缓爬升/缓下降）；
> - 起终点同高 → 行为与既往一致（恒为巡航/抬升高度，受限区剖面语义不变）；
> - **剖面段保持**：受限区底部穿行/顶部绕飞剖面（高度显著偏离巡航高度的路径段）不参与插值，保持 `build_restricted_profiles` 生成的剖面语义；
> - **抬升场景**（地形要求巡航高度抬升）：巡航段高度不低于抬升后巡航高度（既有地形安全裁决），仅终点可继续爬升至目标高度；抬升时起终点保持用户高度（`terrain_alt_raised` warnings 显式提示）；
> - **净空语义**：中间段（距起终点 1km 外巡航段）路径点高度 ≥ 地形 + 净空（100m）保底；**起终点段（1km 内起飞/降落段）允许净空 <100 但不穿地**（2026-08-14：贴地爬升/下降按 15° 平滑线插点，min(地形+净空, 端点+tan(15°)×距离) 且不低于地形）；
> - 每机目标高度来源：`target_ref` 第 3 段（`"lon,lat,alt"`）优先，缺省 = `mission.target.alt_m`；
> - Demo 前端：飞行器表单新增**武器类型下拉框**（不启用/空空导弹 AAM/空地导弹 AGM/航空炸弹）与**射程 Rmin/Rmax 输入框**（缺省按类型默认：AAM [5,40]、AGM [3,120]、Bomb [1,15] km），序列化到 `mission.weapons`（每机至多一条，`weapon_id = "<vehicle_id>_w1"`）。

## 5. InputValidator（config::validate）

入口防线：**畸形/退化输入在进入算法前拦截**，输出专属 `input_invalid` + 原因码。

校验顺序：

1. **schema 版本**：`input.schema_version != "0.20"` → `AppError::Data`（data_error，硬故障语义）；
2. **A/B 起终点**：`to_geo()` 校验合法坐标；`distance_m < 100m` → `degenerate_start_equals_target`；
3. **多机**：
   - 重复 `id` → `vehicle_params_inconsistent`；
   - `validate_vehicle`：速度 ∈ [1, 1000] m/s；速度范围 `[vmin ≤ vmax, vmin > 0]`；
   - **A6 物理自洽**：`(speed, max_bank_deg, min_turn_radius_m)` 同时提供时，`r_min ≥ v²/(g·tan φ_max) × 0.999`，否则拒绝（250 m/s @ 30° → r_min ≈ 11045m；输入 5000m 被拒）；
   - `detection_probability ∈ [0,1]`；
   - 车辆起点在禁飞区 → `target_in_no_fly`；
4. **B 在禁飞区** → `target_in_no_fly`（含 A=B 之外的禁飞包含）；
5. **雷达 ∩ 禁飞区**：雷达位置在禁飞多边形内 → `radar_overlap_no_fly`；`radius_km ≤ 0` → `out_of_bounds`；
6. **参数覆盖数值域**：不再 fail-fast（2026-08-05 决策），由 merge 回落默认并记录 degradations。

### 5.1 几何工具（config.rs 内置）

| 函数 | 说明 |
|------|------|
| `zone_contains(z, p)` | 点是否在 Zone 内（圆：测地距离 ≤ 半径；多边形：射线法经纬度平面近似） |
| `zone_contains_at(z, p, alt, ground)` | 水平 + 高度区间 + AGL 换算 |
| `point_in_polygon` | 射线法（ray casting）点在多边形内 |
| `zone_segment_clearance_km` | 线段到 Zone 水平最小净距（km）。0 = 段穿入或贴边界；多边形端点在内为 0，否则取段到每条边的最近距离；圆形 = 段到圆心最近距离 − 半径 |
| `pt_seg_dist_km` / `seg_seg_dist_km` / `segs_intersect_plane` | 平面近似距离/相交判定（经度按 cos 缩放） |

> `zone_segment_clearance_km` 是 **Theta\* 去锯齿与复验的几何精确判定核心**（主管 2026-08-06：绕飞太贴边 → 考虑飞机机动留转弯空间），替代了早期"等距 16 点采样"方案（采样点可能恰好全落在多边形外部 → 拉直穿过禁飞区内部的漏判）。
