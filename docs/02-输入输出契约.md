# 02 — 输入输出契约与数据校验

> 代码位置：`cli/src/config.rs`（1075 行）、`cli/src/error.rs`（105 行）、`cli/src/main.rs`（105 行）
> 设计依据：技术方案 4.2.1（默认参数表/无解出口/status 契约）、4.5（输入-约束-校验传导矩阵）、十三轮共识（多机契约/InputValidator/压制后距离输入化）

## 1. 总览

CLI 采用 **stdin/stdout JSON 管道**形态：stdin 读任务 JSON → stdout 输出结果 JSON。可选参数 `--input / --output / --seed / --config / --terrain / --grid`。所有字段 `deny_unknown_fields`（未知字段 = 畸形）。

```
main.rs 流程：
  read_input → Input::from_json_str（畸形 → input_invalid: malformed_json）
  → config::validate（InputValidator：退化输入 → input_invalid + 原因码）
  → solver::solve（成功 → Output::success；解算层错误 → input_invalid）
```

**status 四态契约**（输出 JSON 顶层）：

| status | 含义 | 触发 |
|--------|------|------|
| `success` | 规划成功（含每车 `planned` / `no_solution` / `degraded`） | 正常完成 |
| `degraded_timeout` | 超时返回可用结果（warm best-so-far） | 预算耗尽（当前 solver 未显式触发，机制就绪） |
| `no_solution` | 确定性无解 + 原因码 | 全出口链耗尽 |
| `input_invalid` | 非法/退化输入 + 原因码（**不进入算法**） | 解析/校验层拦截 |

> 关键语义：`no_solution` 不是失败，是确定性结论；非零退出（exit 2）只留给硬故障（IO/内部错误）；超时/无解不触发非零退出。

## 2. 输入契约（Input）

```rust
pub struct Input {
    pub schema_version: String,      // 必须 == SCHEMA_VERSION（"0.20"），否则校验拒绝
    #[serde(default)] pub crs: CrsConfig,          // 坐标系声明
    #[serde(default)] pub output_crs: OutputCrsConfig,
    pub mission: Mission,            // 任务（必填）
}
```

### 2.1 CrsConfig（坐标系声明）

```rust
pub struct CrsConfig {
    pub datum: DatumName,               // WGS84（默认）/ CGCS2000 / GRS80
    pub vertical: VerticalName,         // MSL（默认）/ ellipsoid
    pub input_projection: InputProjection, // lonlat（默认）/ utm(u8) / gk3(u8)
}
```

- datum 映射：WGS84 与 GRS80 → `Datum::Wgs84`；CGCS2000 → `Datum::Cgcs2000`。其余 datum fail-fast。
- 输出投影：`lonlat`（默认）/ `utm(u8)` / `gk3(u8)` / `web_mercator`。

### 2.2 Mission（任务）

```rust
pub struct Mission {
    pub start: Waypoint,                    // 起点（必填，顶层字段）
    pub target: Waypoint,                   // 目标点（必填）
    pub vehicles: Vec<VehicleInput>,        // 多机数组（空 → 默认单机 v1）
    pub red_forces: RedForces,              // 红方部署（radars + sams）
    pub no_fly_zones: Vec<Zone>,            // 禁飞区（地面→无限高）
    pub restricted_zones: Vec<Zone>,        // 限飞区（[alt_min, alt_max] 高度带禁入）
    pub obstacles: Vec<Zone>,               // 非地形障碍物（同禁飞区硬阈值语义）
    pub terrain: TerrainConfig,             // 地形源配置
    pub weapons: Vec<WeaponEntry>,          // 武器映射条目
    pub parameters: ParamsOverride,         // 默认参数表覆盖
}
```

**Waypoint**：`{ lon, lat, alt_m }`（经纬度度 + 高程米；高程语义随 crs.vertical，默认 MSL）。构造时经 `Geo::new` 校验（非法经纬度/NaN/Inf → `input_invalid: illegal_coordinate`）。

### 2.5 Zone（禁飞/限飞/障碍物）

```rust
pub struct Zone {
    pub id: String,
    pub zone_type: ZoneType,        // no_fly / restricted / obstacle
    pub shape: ZoneShape,           // circle{center,radius_km} / polygon{vertices}
    pub alt_min_m: Option<f64>,     // 高度区间下界（MSL）；仅 Restricted 使用，
                                    // NoFly/Obstacle 全高度禁入可省略（2026-08-12）
    pub alt_max_m: Option<f64>,     // 高度区间上界；同上（仅 Restricted 使用）
    pub height_semantics: HeightSemantics, // msl（默认）/ agl（仅 Restricted 有意义）
}
```

- `Zone::is_wall()`：NoFly/Obstacle 为**全高度水平墙**（FMM 代价场 INF）；Restricted 为高度层禁入（区间外可穿越，不画墙）。
- **禁飞区无高度范围**（2026-08-12 主管定案）：NoFly/Obstacle 全高度禁入，`alt_min_m`/`alt_max_m` 可省略（省略 = 全高度）；**Restricted 必须提供** `[alt_min, alt_max]`（`alt_min < alt_max`，validator 强制，缺失/倒置 → `out_of_bounds`）。
- AGL 语义：解析层结合地形高程换算 MSL（`zone_contains_at` 实现；ground 未知 → 保守视为在区间内，安全优先）。

## 4. 错误体与错误码（error.rs）

```rust
pub enum AppError {
    Io(std::io::Error),               // → internal_error
    Json(serde_json::Error),          // → input_invalid: malformed_json
    InputInvalid(InputInvalidReason), // → input_invalid + 原因码
    NoSolution(String),               // → no_solution
    DegradedTimeout(String),          // → degraded_timeout
    Data(String),                     // → data_error
    Internal(String),                 // → internal_error
}
```

**InputInvalidReason（原因码，snake_case）**：

| 原因码 | 触发场景 |
|--------|---------|
| `malformed_json` | JSON 语法/结构畸形、类型错误、缺必填、未知字段 |
| `illegal_coordinate` | 经纬度越界 / NaN / Inf |
| `out_of_bounds` | 半径非正、速度越界、detection_probability 出域 |
| `degenerate_start_equals_target` | A 与 B 相同或间距 < 100m |
| `target_in_no_fly` | 目标（或车辆起点）落在禁飞区 |
| `radar_overlap_no_fly` | 雷达位置在禁飞多边形内 |
| `terrain_holes_remain` | 地形空洞残留（预留，当前由数据源语义处理） |
| `vehicle_params_inconsistent` | 重复车辆 ID / 速度范围倒置 / A6 物理自洽失败 |

## 5. InputValidator（config::validate）

入口防线：**畸形/退化输入在进入算法前拦截**，输出专属 `input_invalid` + 原因码。

校验顺序：

1. **schema 版本**：`input.schema_version != "0.20"` → `AppError::Data`（data_error，硬故障语义）；
2. **A/B 起终点**：`to_geo()` 校验合法坐标；`distance_m < 100m` → `degenerate_start_equals_target`；
3. **多机**：
   - 重复 `id` → `vehicle_params_inconsistent`；
   - `validate_vehicle`：速度 ∈ [1, 1000] m/s；速度范围 `[vmin ≤ vmax, vmin > 0]`；
   - **A6 物理自洽**：`(speed, max_bank_deg, min_turn_radius_m)` 同时提供时，`r_min ≥ v²/(g·tan φ_max) × 0.999`，否则拒绝（250 m/s @ 30° → r_min ≈ 11045m；输入 5000m 被拒）；
   - `detection_probability ∈ [0,1]`；
   - 车辆起点在禁飞区 → `target_in_no_fly`；
4. **B 在禁飞区** → `target_in_no_fly`（含 A=B 之外的禁飞包含）；
5. **雷达 ∩ 禁飞区**：雷达位置在禁飞多边形内 → `radar_overlap_no_fly`；`radius_km ≤ 0` → `out_of_bounds`；
6. **参数覆盖数值域**：不再 fail-fast（2026-08-05 决策），由 merge 回落默认并记录 degradations。

### 5.1 几何工具（config.rs 内置）

| 函数 | 说明 |
|------|------|
| `zone_contains(z, p)` | 点是否在 Zone 内（圆：测地距离 ≤ 半径；多边形：射线法经纬度平面近似） |
| `zone_contains_at(z, p, alt, ground)` | 水平 + 高度区间 + AGL 换算 |
| `point_in_polygon` | 射线法（ray casting）点在多边形内 |
| `zone_segment_clearance_km` | 线段到 Zone 水平最小净距（km）。0 = 段穿入或贴边界；多边形端点在内为 0，否则取段到每条边的最近距离；圆形 = 段到圆心最近距离 − 半径 |
| `pt_seg_dist_km` / `seg_seg_dist_km` / `segs_intersect_plane` | 平面近似距离/相交判定（经度按 cos 缩放） |

> `zone_segment_clearance_km` 是 **Theta\* 去锯齿与复验的几何精确判定核心**（主管 2026-08-06：绕飞太贴边 → 考虑飞机机动留转弯空间），替代了早期"等距 16 点采样"方案（采样点可能恰好全落在多边形外部 → 拉直穿过禁飞区内部的漏判）。

## 6. 默认参数表（DefaultParams）

编译期常量，输入未提供时使用；**全部为占位值，Phase 0 校准后才生效**（四轮共识）。要点：

| 参数 | 默认值 | 说明 |

| `radar_inflation` | 1.2 | 球体半径 = 实际探测距离 × 系数 |

| `main_budget_ms` | 2500 | 主算法预算 |
| `degrade_budget_ms` | 500 | 降级链预算 |
| `z_resolution_m` | 50.0 | 垂直分层固定层高（写入数据契约） |
| `fine_success_threshold` | 0.9 | 细层成功率阈值（粗细层收敛判据） |
| `coarse_cell_m` | 2000.0 | FMM 粗层格距 |
| `default_weapon_radius_km` | 10.0 | 表外武器兜底 |
| `default_max_climb_angle_deg` | 15.0 | 固定翼爬升角占位 |
| `default_max_bank_deg` | 30.0 | 最大坡度占位 |
| `default_fixed_wing_turn_radius_m` | 5000.0 | 固定翼转弯半径占位 |
| `default_rotorcraft_turn_radius_m` | 0.0 | 旋翼机 r→0（悬停/原地转向合法） |

**A6 物理自洽公式**（`DefaultParams::physical_turn_radius_m`）：

```
r_min = v² / (g · tan φ_max)      # g = 9.80665
```
