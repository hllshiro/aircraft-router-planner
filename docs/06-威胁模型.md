# 06 — 雷达威胁模型

> 代码位置：`cli/src/threat.rs`（391 行）
> 设计依据：技术方案 4.2.1（雷达威胁代价形态/多雷达合成/压制）、4.3（ThreatModel trait）、十轮主管裁决（探测概率为必选模型）、十二轮共识（LOS mask 乘子语义）

## 1. 设计定位

威胁模型是"默认球形模型（保守探测范围上界）+ 探测概率必选接口"：

- 球形模型：水平距离 ≤ 有效半径（`radius_km × radar_inflation`，被压制时再缩）内视为威胁；
- **探测概率为必选模型（十轮裁决）**：飞机可以穿越雷达探测区，但穿越前提是必须评估探测概率（累计 ≤ P_cross）；
- 多雷达重叠区：默认球体口径保持覆盖 max（保守）；探测概率档用**概率并集 `1−∏(1−pᵢ)`**；
- LOS：地形遮挡雷达视线 → 该雷达不探测（威胁模型内判定）。

## 2. ThreatParams（威胁模型参数）

```rust
pub struct ThreatParams {
    pub radar_inflation: f64,    // 膨胀系数（默认 1.2）
    pub detection_curve: DetectionCurve, // Swerling1（默认）/ Exponential / Linear
    pub p_cross: f64,            // 穿越阈值（默认 0.1，验收阈值）
    pub suppression_delta: f64,  // 压制因子（默认 0.5）
    pub base_p: f64,             // 探测概率基准（已标定 0.9，见下）
}
```

> **base_p 与 P_cross 解耦（主管 2026-08-05，标定后不变）**：P_cross 是验收阈值——调高只放宽"容忍探测"的评估/拉直判定，不应把物理探测概率一起抬高导致代价爆炸 + 强绕行 + 锯齿。
>
> **base_p 标定（2026-08-13 方案 A，Swerling I 典型监视雷达模型）**：`Pd(d) = exp(−VT/(1+SNR))`，`Pfa=1e-6 → VT=ln(1e6)=13.8155`；以有效半径 R_eff 为 **90% 探测距离** → `base_p = Pd(R_eff) = 0.9`，由 `1+SNR₀ = VT/(−ln base_p)` 反解 `SNR₀ = 130.1 ≈ 21.1dB`（与 Skolnik 体系文献"Swerling I Pd=0.9 需 ~21dB"一致）；距离衰减按雷达方程四次方 `SNR(d)=SNR₀·(R_eff/d)⁴`；中心 SNR→∞ → Pd→1（必探测）。R_eff 外 p=0 维持球形契约。

## 3. ThreatModel trait（扩展点）

```rust
pub trait ThreatModel {
    /// 评估整条路径的探测概率（段内等距采样）
    fn evaluate(&self, path: &Path, terrain: Option<&dyn TerrainSource>) -> ThreatReport;

    /// 静态几何探测（无 LOS）：点是否落在任一威胁有效半径内
    fn static_detected(&self, lon, lat, alt_m) -> bool;

    /// 静态几何并集探测概率（无 LOS）：1−∏(1−pᵢ)
    fn static_union_probability(&self, lon, lat) -> f64;

    /// 静态几何穿透深度（无 LOS）：到最近威胁中心的归一化距离 d/R_eff ∈ [0,1]
    /// 0=中心，1=有效半径边缘，>1=有效半径外（无探测）
    fn static_penetration(&self, lon, lat, alt_m) -> f64;

    /// 穿越阈值 P_cross（复验软告警线）
    fn p_cross(&self) -> f64;
}
```

接口为外部雷达模型（多普勒/波束形态）预留；第一版实现为球形。

## 4. SphericalRadarThreat（默认球形实现）

### 4.1 有效探测半径（effective_radius_m）

```
base = radius_km × 1000 × radar_inflation
若 suppression_post_range_km 提供 → 直接使用压制后距离
否则若 suppression_factor 提供 → base × (1 − δ)
否则 → base
```

优先级：**显式压制后距离 > 压制因子 > 无压制**。

### 4.2 单点探测概率（point_probability）

```
p_union = 0
for 每个雷达:
    d = haversine_m(雷达, 点)
    if d > 有效半径: continue
    if 有地形 && !line_of_sight(雷达→点): continue   # LOS 遮挡 → 该雷达不探测
    u = d / 有效半径 ∈ [0,1]
    p = base_p × f(u)
        Swerling1（默认）: f(u) = exp(−VT/(1+SNR₀/u⁴)) / base_p   # 见 §2 标定；u=0→1, u=1→base_p
        Linear:      f(u) = 1 − u
        Exponential: f(u) = exp(−4u)   # R 处 ≈ 1.8%
    p_union = 1 − (1 − p_union) × (1 − p)   # 概率并集
```

### 4.3 LOS 判定（line_of_sight）

雷达天线到点的视线等距 8 点采样：任一点 `Land(h)` 且 `h > 视线高度` → 遮挡；NoData 保守视为遮挡。

### 4.4 路径评估（evaluate）

```
每段等距 SEG_SAMPLES=8 点采样：
    cumulative_p = 1 − ∏(1 − p_点)      # 全程累计（概率并集）
    peak_p / peak_point：单采样点峰值
over_threshold = cumulative_p > p_cross
```

**ThreatReport**：`{ cumulative_p, peak_p, peak_point, over_threshold }`。

### 4.5 静态接口（供 Theta\* 与代价场）

| 接口 | 用途 |
|------|------|
| `static_detected` | 点是否被任一雷达探测（>0） |
| `static_union_probability` | FMM 静态代价场（无 LOS）：cost 放大依据；Theta\* 拉直概率判据 |
| `static_penetration` | Theta\* 去锯齿深穿判定：归一化深度 < 0.7 → 拒绝拉直（保住绕行决策） |

> **Theta\* 拉直双判据（2026-08-13 base_p 标定配套）**：`make_segment_check` 雷达判定 = 几何深穿 <0.7R **或** 静态并集概率 > P_cross 即拒绝拉直——Swerling1 下 0.7R~1.0R 区间探测概率 0.84~0.96 仍远高 P_cross，纯几何判据会放行"弦切圈边缘"的拉直段（端点在外、弦切 0.785R）→ verify 累计 p≈1.0；端点本身已在探测圈内（必经点/目标落在圈内，进圈不可避免）→ 允许拉直（软约束语义，zigzag25 必经点 mid 场景）。

## 5. 雷达代价如何进入 FMM（solver.rs 5b）

```
对每格点:
    p = threat.static_union_probability(lon, lat)
    if p > 0 && cost 有限:
        u = threat.static_penetration(lon, lat, 0.0)
        geom = (u < 1.0) ? (1.0 − u) : 0.0     # 深穿惩罚（探测区外无几何项）
        cost *= 1 + radar_cost_coef × (p + geom)   # coef 默认 200
```

数值效果（默认 coef=200，2026-08-13 标定后 Swerling1）：中心 p→1 → ×(1+200×(1+1))≈×401；0.5R 处 p≈0.993、u=0.5 → ×(1+200×1.49)≈×299；1.0R 处 p=0.9 → ×(1+200×0.9)≈×181——探测圈内全区域强绕行（真实监视雷达圈内高概率探测语义），圈外 p=0 无惩罚。

> **主管 2026-08-06**：并排双雷达不得直穿探测区（即使 P_cross 调高，几何绕行与验收阈值解耦）；Theta\* 深穿判定（<0.7 拒绝拉直）与 FMM 代价同口径。

## 6. 与设计的差异/占位

| 项 | 设计 | 当前实现 |
|----|------|---------|
| base_p 标定 | 真实雷达参数（A2 标定） | ✅ 已标定（2026-08-13 方案 A：Swerling I + Pfa=1e-6，base_p=0.9=R_eff 处探测概率，SNR₀=130.1≈21.1dB，中心→1） |
| LOS mask 乘子进代价场 | `p_det = f(r)·mask_LOS` 预计算 | 威胁模型 LOS 判定已实现（evaluate/point_probability 带地形）；静态 FMM 代价场未含 LOS mask（无地形文件 → 无遮蔽，与 4.2.4 一致） |
| 穿越评估出口② | 探测概率重估代价场找低概率路径 | 当前为"直线直穿替代 + 告警"（solver 内），非整场重算 |
| 探测概率随暴露时间相关 | 暴露时间 = 弦长/速度 | 未显式建模（路径评估为空间采样，未含时间项） |

## 7. 测试覆盖

- Swerling1（默认）/ 线性 / 指数衰减正确性（中心 p=base=0.9，R 处 p≈base 或 0，半程期望值）；Swerling1 专项（中心→1、0.5R≈0.993、R 内公式一致、R 外 0）；
- 多雷达并集（0.18 期望值验证）；
- 压制后距离收缩（0.45° 边界外 p≈0）；
- LOS 山脊遮挡（5000m 山 → p=0；无地形 p>0.03）；
- 路径评估并集与阈值（直穿超阈值、远距离 < 1e-9）；
- crash_suite：空雷达、畸形参数不 panic。
