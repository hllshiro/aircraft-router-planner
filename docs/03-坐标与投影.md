# 03 — 坐标系统与投影

> 代码位置：`cli/src/coord.rs`（446 行）
> 设计依据：技术方案 4.2.3（任务坐标系配置）、4.2.2（高程基准与高度语义）、WKT2 核对记录（2026-08-04，EPSG.io 拉取）

## 1. 职责与设计原则

坐标系统不再是代码内部约定，而是**任务级配置**：输入 JSON `crs` 字段声明、内部自动推导计算面。

核心原则：

- **几何口径钉死（十一轮共识）**：代价场/基元/转弯半径/环带等**一切距离计算定义在本地等距投影（自定义 TM/ENU）**，经纬度仅作 IO 存储——高纬经度间距收缩由投影层吸收；
- **默认零配置可用**：默认输入坐标系 WGS 84（经纬度 + MSL 高程）；
- **WKT2 参数不手抄、不猜**：开发期从 EPSG.io 下载定义文件核对后写入编译期常量，WKT2 文件不随产品分发；
- **投影自研，不引 proj crate**（静态编译红线②）。

## 2. 椭球表（Ellipsoid）

```rust
pub struct Ellipsoid { pub name: &'static str, pub a: f64, pub inv_f: f64 }
```

| 椭球 | 长半轴 a（m） | 扁率倒数 1/f | EPSG | 来源 |
|------|-------------|-------------|------|------|
| WGS 84 | 6_378_137.0 | 298.257_223_563 | 4326 | WKT2 spheroid |
| CGCS2000 | 6_378_137.0 | 298.257_222_101 | 4490 | WKT2 spheroid（与 GRS80 同参数） |
| GRS 1980 | 6_378_137.0 | 298.257_222_101 | — | — |

派生量：短半轴 `b = a(1 − 1/f)`；第一偏心率平方 `e² = f(2 − f)`；第二偏心率平方 `e'² = e²/(1 − e²)`。

**Datum**：Phase 1 椭球级基准（无 7 参数地心变换；跨基准转换属开发期预处理）。`Wgs84` / `Cgcs2000`，各带 EPSG 代码。

## 4. 垂直基准层（VerticalDatum）

```rust

```

- 内置地形一律采用**椭球高**（默认）；

## 5. 横轴墨卡托投影（TransverseMercator，主算面）

**红皮书 Krüger 级数**实现，`|Δλ| ≤ 3°` 内误差 < 1mm。

```rust
pub struct TransverseMercator {
    pub ellipsoid: Ellipsoid,
    pub central_meridian: f64,   // 中央经线（度）
    pub scale_factor: f64,       // UTM=0.9996，GK=1.0，自定义可配
    pub false_easting: f64,
    pub false_northing: f64,
}
```

### 5.1 正算 forward(lon, lat) → (easting, northing)

标准 Krüger 级数：

```
φ = lat·rad, λ = (lon − cm)·rad
n = a / √(1 − e²sin²φ)          # 卯酉圈曲率半径
t = tan²φ,  c = e'²cos²φ,  A = λ·cosφ
M = a[(1 − e²/4 − 3e⁴/64 − 5e⁶/256)·φ
      − (3e²/8 + 3e⁴/32 + 45e⁶/1024)·sin2φ
      + (15e⁴/256 + 45e⁶/1024)·sin4φ
      − (35e⁶/3072)·sin6φ]       # 子午线弧长
x = k₀·n·[A + (1−t+c)·A³/6 + (5−18t+t²+72c−58e'²)·A⁵/120] + FE
y = k₀·[M + n·tanφ·(A²/2 + (5−t+9c+4c²)·A⁴/24 + (61−58t+t²+600c−330e'²)·A⁶/720)] + FN
```

### 5.2 反算 inverse(easting, northing) → (lon, lat)

1. 求足点纬度 φ₁（迭代 8 次牛顿法：`μ = y/(k₀·a·m₀)`，`φ₁ += (y − k₀·M₁)/(a·m₀)`）；
2. 标准 Krüger 反算级数（d = x/(k₀·n₁)，含 r₁ = a(1−e²)/(1−e²sin²φ₁)^1.5）。

### 5.3 便捷构造

| 构造器 | 参数 | 说明 |
|--------|------|------|
| `utm(ellipsoid, lon)` | 经度 | 自动带号（1-60），cm = −183 + 6·zone，k₀=0.9996，FE=500000 |
| `utm_zone(lon)` | 经度 | 带号 = floor((lon+180)/6)+1，clamp [1,60] |
| `gk3(ellipsoid, zone)` | 3° 带号 | cm = zone×3，k₀=1.0，FE=500000（中国 CGCS2000 GK 3°） |

**验证用例**：北京 (116.397, 39.909) → UTM 50N E≈447km N≈4418km；GK3 zone 40（cm=120°E）E≈192km N≈4425.6km。

## 6. Web 墨卡托（EPSG:3857，球形近似）

```rust
pub struct WebMercator;   // R = 6_378_137.0（球形）
forward:  x = R·λ,  y = R·ln(tan(π/4 + φ/2))
inverse:  λ = x/R,  φ = 2·atan(e^(y/R)) − π/2
```

- 纬度 clamp ±85.06°；
- 用于地图瓦片/Web 可视化对接（`output_crs.projection = web_mercator`）；
- 北京验证：x ≈ 12,957,254.8，y ≈ 4,852,727.2。

## 7. 近场 ENU（EnuFrame）

```rust
pub struct EnuFrame { pub origin: Geo }
to_enu:     north = (lat − lat₀)·R,   east = (lon − lon₀)·R·cos(lat₀)
from_enu:   逆运算（cos(lat₀) 下限 1e-9）
```

- 球面近似（R = a = 6378137），覆盖近场 ≤10km 误差 ≤ 米级；
- 用途：起降/近场基元、传感器融合（纯旋转变换，不承担全局计算）。

## 8. 输出投影 codec（ProjectionCodec）

```rust
pub enum ProjectionCodec { LonLat, Utm(TransverseMercator), Gk3(TransverseMercator), WebMercator }
```

- `new(proj, ellipsoid, anchor)`：绑定椭球 + 投影选择；
- `forward/inverse`：仅 IO 边界转换一次，计算面不参与（4.2.3 原则）；
- 场景：`output_crs.projection` 声明 lonlat / utm(zone) / gk3(zone) / web_mercator。
