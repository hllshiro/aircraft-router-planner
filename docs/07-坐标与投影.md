# 07 — 坐标系统与投影

> 设计依据：技术方案 4.2.3（任务坐标系配置）、4.2.2（高程基准与高度语义）

## 1. 职责与设计原则

坐标系统是**任务级配置**：输入 JSON `crs` 字段声明、内部自动推导计算面。

核心原则：
- **几何口径钉死**：一切距离计算定义在本地等距投影（自定义 TM/ENU）
- **默认零配置可用**：默认输入坐标系 WGS 84（经纬度 + MSL 高程）
- **投影自研，不引 proj crate**

## 2. 椭球表

| 椭球 | 长半轴 a（m） | 扁率倒数 1/f | EPSG |

| CGCS2000 | 6_378_137.0 | 298.257_222_101 | 4490 |

**Datum**：Phase 1 椭球级基准（无 7 参数地心变换）。

## 3. 地理坐标（Geo）

```rust
pub struct Geo { pub lon: f64, pub lat: f64 }
```

- `Geo::new(lon, lat)`：构造时校验（NaN/Inf/越界 → `IllegalCoordinate`）
- `distance_m(&other)`：测地距离（米，geo Geodesic 库）

## 4. 垂直基准层

```rust
pub enum VerticalDatum { Ellipsoid, Egm96 }
```

- 内置地形一律采用**椭球高**（默认）
- 高程语义统一：路径点/区域高度均为 MSL 几何高度

## 5. 横轴墨卡托投影（TransverseMercator）

**红皮书 Krüger 级数**实现，`|Δλ| ≤ 3°` 内误差 < 1mm。

```rust
pub struct TransverseMercator {
    pub ellipsoid: Ellipsoid,
    pub central_meridian: f64,
    pub scale_factor: f64,       // UTM=0.9996，GK=1.0
    pub false_easting: f64,
    pub false_northing: f64,
}
```

### 5.1 正算 forward(lon, lat) → (easting, northing)

标准 Krüger 级数（详见源码注释）。

### 5.2 反算 inverse(easting, northing) → (lon, lat)

求足点纬度 → 标准 Krüger 反算级数。

### 5.3 便捷构造

| 构造器 | 参数 | 说明 |
|--------|------|------|
| `utm(ellipsoid, lon)` | 经度 | 自动带号（1-60） |
| `gk3(ellipsoid, zone)` | 3° 带号 | 中国 CGCS2000 GK 3° |

## 6. Web 墨卡托（EPSG:3857）

球形近似，用于地图瓦片/Web 可视化对接。

## 7. 近场 ENU（EnuFrame）

球面近似，覆盖近场 ≤10km 误差 ≤ 米级。用途：起降/近场基元。

## 8. 输出投影 codec

```rust
pub enum ProjectionCodec { LonLat, Utm, Gk3, WebMercator }
```

仅 IO 边界转换一次，计算面不参与。
