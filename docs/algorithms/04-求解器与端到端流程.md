# 04 — 求解器与端到端流程

> 设计依据：技术方案 Phase 4 M1–M5

## 1. 职责

`solver::solve` 把库层组件串成主流程。

**M1 范围**：单机/多机（共享代价场，每机独立 FMM）；Zone 水平几何禁入（高度层 M2）；SmoothOptions 默认值（AircraftProfile 派生 M4）；雷达代价（M3）；逐机显式 target（M5）。

## 2. 求解器主流程

```mermaid
flowchart TD
    START([输入 JSON]) --> PARSE[解析]
    PARSE --> VALID{校验}
    VALID -->|失败| ERR[input_invalid]
    VALID -->|成功| TERRAIN[步骤1: 地形源]

    TERRAIN --> SPEC[步骤2: 飞行器规格]
    SPEC --> REGION[步骤3: 任务区域]
    REGION --> ZONE[步骤4: Zone 集合]
    ZONE --> PARAM[步骤4b: 参数合并]

    PARAM --> COST[步骤5: 语义代价场]
    COST --> FILTER[步骤5d: 地形高度过滤]
    FILTER --> INFLATE[步骤5c: 禁飞墙膨胀]
    INFLATE --> RADAR[步骤5b: 雷达代价]
    RADAR --> ALT[步骤5e: 起终点高度]

    ALT --> LOOP[步骤6: 每机循环]
    LOOP --> FMM[FMM 传播]
    FMM --> BACK[回溯]
    BACK --> SMOOTH[平滑链]
    SMOOTH --> VERIFY{复验}

    VERIFY -->|通过| OUT[输出路径]
    VERIFY -->|失败| FALL[回退]
    FALL --> LINE{直线?}
    LINE -->|通过| OUT
    LINE -->|失败| NO[no_solution]

    OUT --> RESULT([输出 JSON])
    NO --> RESULT
    ERR --> RESULT

    style START fill:#e1f5fe
    style RESULT fill:#e8f5e8
    style ERR fill:#ffcdd2
    style NO fill:#ffcdd2
    style OUT fill:#c8e6c9
```

## 3. 两轮 FMM 机制

```mermaid
flowchart TD
    START([开始]) --> FMM1[第一轮 FMM<br>只绕硬墙<br>restricted 直穿]

    FMM1 --> RAW[回溯 raw 路径]
    RAW --> CHECK{剖面段<br>穿硬墙?}

    CHECK -->|否| SMOOTH[平滑]
    CHECK -->|是| FMM2[第二轮 FMM<br>restricted 画墙]

    FMM2 --> RAW2[回溯 raw 路径]
    RAW2 --> SMOOTH

    SMOOTH --> VERIFY{复验}
    VERIFY -->|通过| OUT([输出])
    VERIFY -->|失败| NEXT[下一尝试]

    NEXT --> FMM1

    style START fill:#e1f5fe
    style OUT fill:#e8f5e8
    style FMM1 fill:#bbdefb
```

## 4. 受限区剖面决策

```mermaid
flowchart TD
    START([飞行高度在<br>restricted 区间]) --> CHECK{底部可行?}

    CHECK -->|是| BOTTOM[底部穿行<br>alt_min - 500m]
    CHECK -->|否| CHECK2{顶部可行?}

    CHECK2 -->|是| TOP[顶部绕飞<br>alt_max + 500m]
    CHECK2 -->|否| WALL[画墙水平绕行]

    BOTTOM --> DONE([决策完成])
    TOP --> DONE
    WALL --> DONE

    style START fill:#e1f5fe
    style BOTTOM fill:#c8e6c9
    style TOP fill:#c8e6c9
    style WALL fill:#ffcdd2
```

**底部可行条件**：
- bottom ≥ 0（负高不可行）
- 爬升距离够
- 穿行带地形可行

**顶部可行条件**：
- 爬升距离够
- top ≤ 升限

## 5. 平滑链 + 回退机制

```mermaid
flowchart TD
    START([raw 路径]) --> THETA[Theta* 去锯齿]
    THETA --> CATMULL[Catmull-Rom]
    CATMULL --> DUBINS[Dubins 拟合]
    DUBINS --> SIMPLIFY[贪心抽稀]

    SIMPLIFY --> VERIFY{复验}
    VERIFY -->|通过| OUT([输出平滑路径])
    VERIFY -->|失败| BACK[回退到上一阶段]

    BACK --> CHECK{全链<br>失败?}
    CHECK -->|否| VERIFY2{回退阶段<br>复验}
    CHECK -->|是| RAW[交付 raw]

    VERIFY2 -->|通过| OUT
    VERIFY2 -->|失败| BACK

    RAW --> LINE{直线替代?}
    LINE -->|通过| OUT2([输出直线])
    LINE -->|失败| RADAR{雷达直穿?}
    RADAR -->|通过| OUT3([输出直穿])
    RADAR -->|失败| NO[no_solution]

    style START fill:#e1f5fe
    style OUT fill:#c8e6c9
    style OUT2 fill:#c8e6c9
    style OUT3 fill:#c8e6c9
    style NO fill:#ffcdd2
    style RAW fill:#fff9c4
```

**关键决策**：不交付违禁路径——平滑全失败 + 直线替代均失败 → no_solution。

## 6. 垂直剖面后处理（方案 B）

```mermaid
flowchart TD
    START([平滑路径]) --> PROFILE[apply_vertical_profile]

    PROFILE --> INSERT[terrain_follow_insert<br>250m 峰顶捕获]
    INSERT --> CLIMB[apply_climb_rate<br>双向 ≤15°]

    CLIMB --> CHECK{起终点<br>低于地面?}
    CHECK -->|是| RAISE[抬升到地面]
    CHECK -->|否| DONE([完成])

    RAISE --> DONE

    style START fill:#e1f5fe
    style DONE fill:#e8f5e8
    style INSERT fill:#bbdefb
    style CLIMB fill:#bbdefb
```

**方案 B 核心**：
- 起终点保持用户高度（硬约束）
- 中间段抬升决策记录撞山区段最高地形点 → 自动中间锚点
- terrain_follow_insert：段内 250m 加密采样找最差峰插点
- apply_climb_rate：限制相邻路径点坡度 ≤ 15°
