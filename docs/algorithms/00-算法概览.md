## 2. 处理流程详解

### 2.1 完整流程图

```mermaid
flowchart TD
    START([输入 JSON]) --> PARSE[解析]
    PARSE --> VALID{校验}
    VALID -->|失败| ERR[input_invalid]
    VALID -->|成功| LOAD[加载地形<br>ARPK1/SRTM/GeoTIFF]

    LOAD --> COST[构建语义代价场<br>Land=1, NoData=5x, Forbidden=INF]
    COST --> INFLATE[禁飞墙膨胀<br>+ 过渡带软罚]
    INFLATE --> RADAR[雷达静态代价<br>× 1+200×p]

    RADAR --> FMM[FMM 传播<br>2D 水平传播]
    FMM --> BACK[回溯<br>T 场下降方向]

    BACK --> THETA[Theta* 去锯齿<br>贪心跳点]
    THETA --> CATMULL[Catmull-Rom 样条]
    CATMULL --> DUBINS[Dubins 拟合<br>CSC/CCC]
    DUBINS --> SIMPLIFY[贪心抽稀<br>弦高容差]

    SIMPLIFY --> VERIFY{全链复验}
    VERIFY -->|通过| VPROFILE[垂直剖面<br>地形跟随]
    VERIFY -->|失败| FALLBACK[回退]

    FALLBACK --> LINE{直线?}
    LINE -->|通过| VPROFILE
    LINE -->|失败| RADAR2{雷达直穿?}
    RADAR2 -->|通过| VPROFILE
    RADAR2 -->|失败| NO[no_solution]

    VPROFILE --> OUTPUT([输出 JSON])
    NO --> OUTPUT
    ERR --> OUTPUT

    style START fill:#e1f5fe
    style OUTPUT fill:#e8f5e8
    style ERR fill:#ffcdd2
    style NO fill:#ffcdd2
    style FMM fill:#fff3e0
    style THETA fill:#c8e6c9
    style VERIFY fill:#bbdefb
```

### 2.2 流程阶段说明

| 阶段 | 作用 | 关键算法 |
|------|------|---------|
| **输入校验** | 拦截畸形/退化输入 | InputValidator |
| **地形加载** | 加载地形数据（ARPK1/SRTM/GeoTIFF） | TerrainSource trait |
| **语义代价场** | 构建网格代价（Land=1, NoData=5x, Forbidden=INF） | build_semantic_cost_field |
| **禁飞墙膨胀** | 扩展安全距离 + 过渡带软罚 | apply_inflation_and_band |
| **雷达代价** | 探测概率叠加到代价场 | static_union_probability |
| **FMM 传播** | 粗层走廊定方向 | Godunov 迎风差分 |
| **回溯** | 从终点沿 T 场下降提取路径 | backtrack_path |
| **Theta\*** | 去锯齿，贪心跳点简化 | theta_star_smooth |
| **样条/Dubins** | 平滑拟合 | Catmull-Rom / Dubins CSC/CCC |
| **贪心抽稀** | 减少路径点数 | greedy_simplify |
| **全链复验** | 验证安全性/运动学 | verify_path |
| **垂直剖面** | 地形跟随 + 爬升率约束 | apply_vertical_profile |

## 3. 核心算法详解

### 3.1 FMM（快速行进法）

**作用**：粗层走廊规划，确定路径大方向。

```mermaid
graph LR
    subgraph 输入
        COST[代价场<br>2D 网格]
        SRC[源点<br>start]
        DST[目标点<br>target]
    end

    subgraph FMM
        PROP[Godunov 迎风差分<br>BinaryHeap 窄带]
    end

    subgraph 输出
        TIME[T 场<br>到达时间]
        PATH[回溯路径]
    end

    COST --> PROP
    SRC --> PROP
    DST --> PROP
    PROP --> TIME
    TIME --> PATH

    style PROP fill:#fff3e0
```

**核心思想**：从源点向外传播，每个格点记录到达时间，终点沿 T 场下降方向回溯得到路径。

**确定性保证**：HeapEntry 的 Ord 实现反转比较，tie-break 固定 idx。

### 3.2 语义代价场

**作用**：将地形/Zone/雷达信息编码为网格代价，指导 FMM 传播。

```mermaid
graph TB
    subgraph 输入
        TERRAIN[地形<br>Land/Water/NoData]
        ZONE[Zone<br>NoFly/Restricted]
        RADAR[雷达<br>探测概率]
    end

    subgraph 代价计算
        BASE[基础代价<br>Land=1, NoData=5x]
        WALL[硬墙代价<br>Forbidden=INF]
        INFLATE[膨胀<br>安全距离]
        RADAR_COST[雷达代价<br>× 1+200×p]
    end

    subgraph 输出
        COST[语义代价场<br>2D 网格]
    end

    TERRAIN --> BASE
    ZONE --> WALL
    BASE --> INFLATE
    WALL --> INFLATE
    INFLATE --> RADAR_COST
    RADAR --> RADAR_COST
    RADAR_COST --> COST

    style COST fill:#fff3e0
```

**三层叠加**：
1. 语义层：Land/Water/Lake=1.0，NoData/OOB=5x，Forbidden=INF
2. 膨胀层：禁飞墙向外扩展 + 过渡带软罚
3. 雷达层：探测概率叠加到代价

### 3.3 平滑链

**作用**：将 FMM 输出的折线路径平滑为可飞行路径。

```mermaid
graph LR
    subgraph 输入
        RAW[raw 折线<br>锯齿路径]
    end

    subgraph 平滑链
        T[Theta*<br>去锯齿]
        C[Catmull-Rom<br>样条拟合]
        D[Dubins<br>CSC/CCC]
        S[贪心抽稀<br>减少点数]
    end

    subgraph 输出
        SMOOTH[平滑路径<br>可飞行]
    end

    RAW --> T
    T --> C
    C --> D
    D --> S
    S --> SMOOTH

    style RAW fill:#ffcdd2
    style SMOOTH fill:#c8e6c9
```

**算法选择**：
- **Theta\***：LOS 捷径简化，贪心跳点
- **Catmull-Rom**：样条插值，保持曲率连续
- **Dubins**：CSC 四类型 + CCC 三圆弧，满足转弯半径约束
- **贪心抽稀**：弦高容差内减少点数

### 3.4 全链复验

**作用**：验证路径安全性/运动学约束，不满足则回退。

```mermaid
flowchart TD
    START([输入路径]) --> TERRAIN{地形净空?}
    TERRAIN -->|通过| ZONE{禁飞/限飞?}
    TERRAIN -->|失败| FAIL([失败])

    ZONE -->|通过| KINEMATIC{运动学?}
    ZONE -->|失败| FAIL

    KINEMATIC -->|通过| RADAR{雷达威胁?}
    KINEMATIC -->|失败| FAIL

    RADAR -->|通过| PASS([通过])
    RADAR -->|warning| PASS

    style START fill:#e1f5fe
    style PASS fill:#c8e6c9
    style FAIL fill:#ffcdd2
```

**复验清单**：

| 检查项 | 作用 | 机型 |
|--------|------|------|
| 地形净空 | 防撞山 | 两机型 |
| 禁飞/限飞 | 防越界 | 两机型 |
| 航向连续性 | 防急转 | 固定翼 |
| 转弯半径 | 满足机动约束 | 固定翼 |
| 爬升角 | 满足爬升能力 | 固定翼 |
| 弦高 | 保持路径质量 | 两机型 |
| 雷达威胁 | 软告警 | 两机型 |

### 3.5 回退机制

**作用**：平滑失败时尝试替代方案，最终保证不交付违禁路径。

```mermaid
stateDiagram-v2
    [*] --> Theta*: 开始平滑
    Theta* --> CatmullRom: 通过
    Theta* --> Dubins: 失败
    CatmullRom --> 输出: 通过
    CatmullRom --> Theta*: 失败
    Dubins --> 输出: 通过
    Dubins --> CatmullRom: 失败

    state "全链失败" as Failed
    Failed --> 直线替代: 尝试
    直线替代 --> 输出: 通过
    直线替代 --> 雷达直穿: 失败
    雷达直穿 --> 输出: 通过
    雷达直穿 --> no_solution: 失败

    输出 --> [*]: 交付
```

**关键决策**：不交付违禁路径——平滑全失败 + 直线替代均失败 → no_solution。

## 5. 关键设计决策

| 决策 | 原因 |
|------|------|
| **确定性** | 固定种子逐位可复现，构建期禁 FMA + 固定 target-cpu |
| **分层解耦** | 粗层定方向，细层保可行，复验保安全 |
| **不交付违禁路径** | 安全优先，宁可 no_solution 也不给违禁路径 |
| **回退机制** | 平滑失败 → 直线替代 → 雷达直穿 → no_solution |
| **软硬约束分离** | 地形/禁飞硬约束，雷达软告警 |

## 6. 性能预算

| 环节 | 预算 | 说明 |
|------|------|------|
| FMM 粗层 | ~15% | 多机共享摊薄 |
| 雷达/禁飞查询 | ~30% | rstar 空间索引 |
| 平滑链 | ~20% | Dubins/样条拟合 |
| 复验 | ~35% | 全分辨率采样 |

**总体目标**：每百公里 ≤ 3s（端到端典型值）
