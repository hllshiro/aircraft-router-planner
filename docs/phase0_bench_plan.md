## B1 实测结果（2026-08-04，S2 完成）

场景：100km，合成代价场（平滑地形正弦叠加 + 3 雷达球 30x + 2 禁飞区矩形 50x），固定种子确定性。

| 网格 | 格距 | 单次传播耗时 |
|------|------|-------------|
| 64² | 1.56km | 613 µs |
| 128² | 781m | 2.62 ms |
| 256² | 390m | 11.57 ms |
| 512² | 195m | 52.2 ms |
| 100 源×128²（100 组随机起止） | — | 248.7 ms（单次 ≈2.49 ms） |

- **O(NlogN) 实际常数 ≈ 11.0–12.5 ns/操作**（四档稳定；规模×4 耗时×4.5）
- **走廊质量（128²，100 组随机起止）**：可达率 100/100，平均路径 133.9 步，平均绕行比 2.02，最差 6.45（合成障碍密度高于典型任务，绕行比偏高属场景参数）
- **预算判定：PASS** —— 15% 初始预算（≈450ms/3s 口径）下：100 次独立传播 248.7ms、512² 单次 52ms，均达标且余量充足（基准硬件为 2017 年老平台）

## B2 实测结果（2026-08-04，S3 完成）

场景：128²（781m，100km），N=10 机。

| 场景 | 策略 | 总耗时 | 摊薄系数 |
|------|------|--------|---------|
| 同源（10 机同起点） | 独立（10 次传播） | 24.84 ms | — |
| 同源 | 共享（1 传播 + 10 回溯） | 2.43 ms | **10.2x** |
| 异源（10 机各自起止） | 独立（10×(构建+传播)） | 28.41 ms | — |
| 异源 | 共享（1 构建 + 10 传播） | 24.83 ms | **1.14x** |

- **内存**：128² 每场 80 KiB（times f32 + accepted u8）；10 场 0.8 MiB（512² 时 12.8 MiB，无压力）
- **多机契约落定**：
  1. 同源（编队/同基地）→ 共享传播场，摊薄 ≈ N 倍，**同源必共享**；
  2. 异源 → FMM 单源语义下传播不可共享，每机独立传播；**代价场构建全局共享一次**（摊薄 1.14x）；
  3. 回溯开销可忽略（10 次回溯 ≈ 传播的 3% 以内）

## B3 实测结果（2026-08-04，S4 完成）

场景：100km 立方体，N=100 雷达（3D 球体，半径 8–15km）+ 50 禁飞区棱柱。

| 指标 | 结果 |
|------|------|
| 索引构建 100 雷达 / 50 禁飞区（bulk_load） | 22.6 µs / 6.4 µs |
| 线段范围查询（1000 条） | 621.7 µs（单查询 0.62 µs，平均候选 30.7/条） |
| 禁飞区棱柱线段查询 | 268.7 µs（单查询 0.27 µs） |
| 最近邻（1000 点） | 1.238 ms（单查询 1.24 µs） |
| 暴力遍历 100 雷达 | 407.4 µs（单查询 0.41 µs） |

- **结论：N=100 时 rstar 范围查询略慢于暴力（0.62 vs 0.41 µs，树遍历开销主导），但候选剪枝 3.3x（30.7 vs 100）**——碰撞判定成本随候选数线性（精确球面距离检查），N 更大（真实多机+动态禁飞区场景）rstar 优势显著；构建开销可忽略
- **预算判定：PASS** —— 1000 条线段全量碰撞检查（rstar 范围 + 候选精确检查）≈1ms ≪ 30% 预算（≈900ms）；索引构建 22.6µs 一次

## B4 实测结果（2026-08-04，S5 完成）

场景：100km，合成地形全分辨率 152.87m 语义（654²），1000 条随机射线（3–10km 高、60km 长、1000 采样点/条）。

| 配置 | 1000 条射线总耗时 | 单射线 |
|------|-----------------|--------|
| 全分辨率 654² | 13.42 ms | 13.4 µs |
| LOD 2x（305.7m，327²） | 12.98 ms | 13.0 µs |
| LOD 4x（611.5m，163²） | 12.93 ms | 12.9 µs |

- **关键发现：网格 LOD 降采样几乎不省时**（双线性插值 O(1)，耗时由采样点数主导、与网格尺寸无关；654²=1.7MB 与 327²=0.4MB 仅差缓存局部性）——**省时靠控制采样点数/射线数，非网格降采样**
- **遮挡一致性：LOD 2x/4x 与全分辨率 100% 一致**（合成场景 69/69；真实 SRTM 高频信号可能更敏感，B4 待真实数据双跑）
- **预算判定：PASS** —— 1000 条 LOS 检查 13.4ms ≪ 40% 预算（≈1200ms）；单射线 13.4µs → 3s 预算可容纳 ≈9 万次 LOS 检查

## B4 真实数据双跑：B6 射线-地形求交（2026-08-04，Beijing_DEM 测试数据）

数据：Beijing_DEM（1.236 弧秒 ≈ 29–38m，Int16 0 空洞 → Float32 NaN 预处理，4712×6091 行优先，矩形 cell 38.09×29.28m，有效 51.3%）。射线：有效区域起点 + 相对地面 500–3000m 低空水平射线（绝对 3–10km 在北京最高 2273m 场景永不被挡，必须相对地形，贴合 LOS 语义），60km 长、1000 采样点/条、1000 条。

| 配置 | 1000 条射线总耗时 | 单射线 | 相对全量 |
|------|-----------------|--------|---------|
| 全量 4712×6091 | 35.10 ms | 35.1 µs | 1.00x |
| LOD 2x（2356×3045） | 25.30 ms | 25.3 µs | 0.72x |
| LOD 4x（1178×1522） | 17.75 ms | 17.7 µs | 0.51x |

- **遮挡一致性：full/2x/4x 100% 一致（55/55 blocked）**——真实数据 LOD 无精度损失，与合成结论相同
- **合成对照**：同批射线在合成全有效 654² 上 blocked=196（19.6%）vs 真实 55（5.5%）——真实更平缓 + 空洞影响
- **空洞影响（重要发现）：Beijing 48.7% 空洞 → 射线穿越空洞段视为不遮挡 → blocked 率系统性偏低（5.5% vs 全有效 19.6%）→ LOS 低估 → 探测概率偏高（非保守侧）**。Phase 1 必须定义空洞处理（插值填充/排除），不能静默放行
- **性能：真实全量 35.1µs vs 合成 13.4µs**——网格 28.7M vs 429k 像素（67x），缓存局部性劣化 → 2.6x 慢；仍远低于预算（3s 预算 ≈8.5 万次 LOS）
- 加载：全量 109.5MiB（f32）/0.06–0.1s；2x 27.4MiB；4x 6.8MiB——加载无压力
- **预算判定：PASS（同 B4）**

## B1 真实双跑：B7 真实地形代价场 FMM（2026-08-04，Beijing_DEM 测试数据）

链路：Beijing 全量加载（0.06s）→ 块平均降采样 1.5km 粗层（119×118）→ 代价场（海拔 >1500m 线性升高 ≤20x 模拟山区绕飞；空洞块有效占比 <25% → 100x 空洞墙，保守禁行）。

- 代价场构成：空洞墙 46.5%（6529 格）、山区 0.3%、平坦 53.2%
- **单次传播 2.25ms / 100 随机源 204ms**——与合成 128²（2.62ms / 248.7ms）相当（规模 119×118 vs 128²，O(NlogN) 常数一致）
- **走廊质量：可达率仅 33/100**（可达对绕行比 1.28，FMM 行为正常）——**空洞墙把有效数据切成多个孤立岛**（Beijing 环形空洞带在粗层放大），**空洞处理策略直接影响路径规划可用性：禁行=保守但断连**。正式数据空洞结构未知，Phase 1 需裁决空洞处理（填充/禁行/代价权衡）
- **预算判定：PASS（同 B1）**——真实地形代价场下 FMM 耗时无显著变化

## B5 实测结果（2026-08-04，S6 完成）

场景：100km 走廊，100 组随机起止（位置+航向），Dubins CSC 基元（LSL/RSR/LSR/RSL），R=5km（A6 速度-转弯半径自洽参考）。

| 指标 | 结果 |
|------|------|
| 单段求解耗时 | 1.62 µs（100 次 137.6µs） |
| 拟合成功率 | **95/100 = 95.0%**（≥90% 判据 PASS） |
| 失败归因 | 5 个失败样本全部 d<2R（距离 <10km，CSC 无解，CCC 未实现） |
| 平均单段长度 | 64.0 km |

- **结论：细层基元预算 PASS**（100 段拟合 0.14ms ≪ 10% 预算 ≈300ms）；成功率达标且失败 100% 可归因（CCC 补全后预期 ~100%）
- **Dubins 实现说明**：自研 CSC 解析求解 + 航向连续性筛选（单元测试验证直行/垂直/同点/退化 4 场景）；CCC 类型留正式实现

## 场景数据策略

- **合成地形（默认先行）**：程序生成——平滑地形（低分辨率正弦叠加）+ 高频噪声区（模拟 SRTM 高频信号，用于压缩率预估与求交基准）；网格分辨率 152.87m 语义（赤道≈5 弧秒，等经纬度）
- **真实 SRTM / 内置数据包（数据到位后）**：B4/B6/B7 用真实数据重跑（压缩率实测门 + t_load_decompress 落账）

## 验收口径（方案 5.2 双基准）

- 端到端：启动 → stdout 输出可用航路结果集（六轮主管裁决）

- 双基准：法定 SRTM + 交付内置包（B4/B6/B7 双跑）
